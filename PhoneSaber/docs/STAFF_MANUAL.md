# 縁日セイバー スタッフマニュアル(簡潔版)

スマホのカメラが光る剣を見て、PC のゲームに動きを送ります。A台・B台は別々に動きます。
**困ったら、その台の受付を止める。表の操作で戻らなければ技術担当を呼ぶ。**
詳しい手順は技術担当が [EVENT_DAY_RUNBOOK.md](claude/EVENT_DAY_RUNBOOK.md) で確認します。

## 1. 開場前(A台・B台それぞれ)

1. PC・スマホ・箱の「A」「B」の目印がそろっているか見る。
2. PC とスマホを電源につなぎ、同じ Wi-Fi につなぐ。スマホは箱に縦向きで固定し、レンズをプレイヤー側へ向ける。
3. PC で、この台の起動ファイルをダブルクリックする。
   - Mac:「Start-Saber-A.command」/「Start-Saber-B.command」
   - Windows:「Start-Saber-A.bat」/「Start-Saber-B.bat」
   - ゲームが出なければ下の表へ。起動時に出た文字を技術担当に見せる。
4. スマホのアプリを開き、「台」をこの台(A か B)にして、送信を開始する。
   - iPhone:「通常送信を開始」/ Android:「開始」
   - 「起動時に送信を自動開始」は ON にしておく（最初は OFF）。
   - PC の番号を手入力してある場合は、開始前に技術担当に確認してもらう。
5. ゲーム画面の右上の端をクリックして **F8** を押す(Mac で効かなければ Fn+F8)。赤・青の剣を両方点灯してカメラに映し、5秒待って次を確認する。表示は下へスクロールできる。

| 見るところ | OK の目安 |
| --- | --- |
| 台: | この台と同じ(A / B) |
| RED・BLUE の pkt/s | どちらも 0 より大きい(多くは 40〜60、30 の端末もある) |
| 判定: | 両色とも「良好（間隔のみ）」 |

6. 剣を動かして、画面の剣が同じ向きに動くか見る。もう一方の台が動いたり、ずれたりしたら技術担当へ。
7. F8 を押して表示を閉じる。

## 2. 営業中

- お客さんは床の表示の位置に立ってもらう。プレイ範囲(直径 1.5m)に他の人を入れない。
- 交代のたびにスマホの「発熱」を見る。「高い」「危険」なら下の表へ。
- スマホは充電したまま。アプリは画面に出したまま。画面が消えたらロックを解除してアプリへ戻すと、送信中だった場合は自動で再開する。
- 「停止」を押した後は、アプリを画面に戻すだけでは再開しない（自動開始ONなら次のアプリ起動では再開する）。営業を再開するときだけ開始ボタンを押す。

## 3. 困ったとき（受付を止めてから）

**表の操作は1回だけ。戻らなければ技術担当へ。ゲームを何度も開き直さない。**

| 症状 | 一つの対処 |
| --- | --- |
| 剣が動かない・スマホの画面が消えた | ロックを解除してスマホのアプリを画面に戻す。 |
| スマホに「開始」「通常送信を開始」が出ている | その開始ボタンを押す。 |
| iPhoneに「応答がありません」を含む表示 | 技術担当にスマホの表示を見せる。 |
| カメラ映像が止まった | アプリを画面に戻して30秒待つ。 |
| 剣がガタガタ・ずれる | 箱・スマホの固定とレンズの前を確認する。 |
| 発熱「高い」・「発熱のため 30fps に下げています」 | 箱を開けて風を通す（冷えると自動で元に戻る）。 |
| 発熱「危険」 | スマホの「停止」を押す。 |
| スマホに「充電されていません」「電池が」と出た | 充電ケーブルを差し直す。 |
| 起動時に「異常終了」「5秒後に再起動」と出た | 5秒待つ（起動し始めてから画面が出るまで時間がかかる）。 |
| ゲームを正常終了した・理由不明で消えた | 技術担当に起動し直してもらう。 |
| ゲームの画面が固まった・F8も効かない | 60秒待つ（開場前に確認した自動復旧を待つ）。 |
| 起動時に「STOP ファイル」「停止ファイル」「既に」と出た | 出た文字を技術担当に見せる。 |
| 別の台が動く・台が違う | 技術担当に台と手入力のPC番号を直してもらう。 |

※発熱「危険」の後は、冷却・予備スマホへの交代を技術担当に頼む。
※Windows のゲーム起動と Android(AQUOS)の復帰は、本番機材で開場前に技術担当が確認する。

## 4. 片付け

1. スマホの「停止」を押し、「起動時に送信を自動開始」を OFF にする。
2. ゲームのタイトル画面右下の × を2秒長押しして正常終了する（自動では起動し直さない）。
3. スマホと箱が冷めてからしまう。
