# 縁日セイバー スタッフマニュアル(簡潔版)

スマホのカメラが光る剣を見て、PC のゲームに動きを送ります。A台・B台は別々に動きます。
**困ったら、その台の受付を止めて技術担当を呼ぶ。** 詳しい手順は技術担当が [EVENT_DAY_RUNBOOK.md](claude/EVENT_DAY_RUNBOOK.md) で確認します。

## 1. 開場前(A台・B台それぞれ)

1. PC・スマホ・箱の「A」「B」の目印がそろっているか見る。
2. PC とスマホを電源につなぐ。スマホは箱に縦向きで固定し、レンズをプレイヤー側へ向ける。
3. PC で、この台の起動ファイル(「Start-Saber-A」または「Start-Saber-B」)をダブルクリック。ゲームが出れば OK。
4. スマホのアプリを開き、「台」をこの台(A か B)にして、送信を開始する。
   - iPhone:「通常送信を開始」 / Android:「開始」
   - 「起動時に送信を自動開始」は ON にしておく。
5. ゲーム画面で **F8** を押す(Mac で効かなければ Fn+F8)。赤・青の剣を両方カメラに映し、5秒待って次を確認する。

| 見るところ | OK の目安 |
| --- | --- |
| 台: | この台と同じ(A / B) |
| 赤・青の pkt/s | どちらも 0 より大きい(iPhone は 60、Android は 30 くらい) |
| 判定: | 両色とも「良好(間隔のみ)」 |

6. 剣を動かして、画面の剣が同じ向きに動くか見る。ずれていたら技術担当(F7 で位置合わせ)。
7. F8 を押して表示を閉じる。

## 2. 営業中

- お客さんは床の表示の位置に立ってもらう。プレイ範囲(直径 1.5m)に他の人を入れない。
- 交代のたびにスマホの「発熱」を見る。「高い」「危険」なら下の表へ。
- スマホは充電したまま。アプリは画面に出したまま。

## 3. 困ったとき

| 症状 | まずやること | だめなら |
| --- | --- | --- |
| 剣が動かない | スマホのアプリを画面に戻す。止まっていたら開始ボタン | F8 で pkt/s を見て技術担当へ |
| 剣がガタガタ・ずれる | スマホがぐらついていないか、レンズが隠れていないか見る | 技術担当(反転・位置合わせ) |
| スマホが熱い | 箱を開けて風を通す。充電中か見る | 「危険」が続いたら送信を止めて技術担当(予備スマホ) |
| ゲームが落ちた | 5秒待つ(自動で起動し直す) | 何度も落ちたら受付を止めて技術担当 |
| カメラ映像が止まった | アプリを画面に戻して 30 秒待つ。iPhone は「カメラを再開」、Android は停止→開始 | 技術担当(予備スマホ) |
| 別の台につながった | スマホで「停止」→「台」を正しい A / B に直す→開始 | 技術担当 |

※ Windows の PC と Android(AQUOS)は、まだ本番の機材で試していません。開場前に技術担当と一度動かしてください。

## 4. 片付け

1. スマホの「停止」を押し、「起動時に送信を自動開始」を OFF にする。
2. ゲームのタイトル画面右下の × で終了する。
3. スマホと箱が冷めてからしまう。
