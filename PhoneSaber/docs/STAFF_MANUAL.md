# 3D-Saber 当日スタッフマニュアル

## はじめに

スマホのカメラで赤・青の光る剣を見つけ、PC（パソコン）のゲームに動きを送ります。
プロジェクターに映った剣を動かして遊びます。スマホでゲームを操作する必要はありません。

```text
 A台：赤・青の剣 → Aのスマホ → AのPC → Aのプロジェクター
 B台：赤・青の剣 → Bのスマホ → BのPC → Bのプロジェクター
                    撮影      ゲーム       画面
```

**A台を準備して最終チェックを終えてから、B台も同じ手順で準備します。**
困ったらその台の受付を止め、末尾の連絡先に記入した「技術担当」を呼びます。
機材の交換・設定変更後は、最終チェックが終わるまでお客さんを入れません。

※未確認：Windowsでの実機運転、AndroidのAQUOS sense9での実機運転、長時間運転。
開場前に、当日使う機材で技術担当と確認してください。

## 用意するもの

- [ ] A・BそれぞれのPC、スマホ、プロジェクター、赤・青の光る剣
- [ ] PC・スマホ・箱の「A」「B」の目印
- [ ] 電源、充電器、ケーブル、スマホの固定具、通風できる箱、送風の用意
- [ ] 背後の幕、立ち位置とプレイ範囲の床表示
- [ ] 当日用Wi-Fi（機器を無線でつなぐ仕組み）の名前・接続用パスワード
- [ ] 予備スマホ・予備PC、末尾に記入した連絡先
- [ ] 技術担当が準備したゲーム・スマホアプリ・台別の起動ファイル

技術担当の事前確認：スマホのカメラ許可、iPhoneの「ローカルネットワーク」許可
（近くのPCと通信する許可）、通知・自動ロックの対策、Windowsの通信許可を済ませる。
MacとiPhoneを直接つなぐ場合は、その接続用の準備も済ませる。
ゲームの作成やアプリの導入は、このマニュアルでは扱いません。

## 開場前の準備

### A台・B台それぞれの置き方

1. 担当する台の機材の目印を確認する。PC・スマホ・箱がすべて同じAまたはBならOK。
2. PCを電源につなぐ。電源が入ればOK。
3. スマホを充電器につなぐ。充電の表示が出ればOK。
4. スマホを画面下の箱に縦向きで固定する。レンズが隠れず、プレイヤー側を向いていればOK。
5. 箱の通風を確認する。空気の通り道があり、PCの熱い風が当たらなければOK。
6. 会場の配置を確認する。2台は背中合わせ、入口は別々、一方通行ならOK。
7. 床表示を確認する。立ち位置は画面から約2.7〜3.1m、プレイ範囲は直径1.5mならOK。

以降の「この台」は、A台の準備中ならA、B台ならBです。

### PCがMacの場合

1. 技術担当に前回の再起動停止用ファイルが残っていないか確認してもらう。起動ファイル横の `Start-Saber-A.STOP`／`Start-Saber-B.STOP` と `STOP` がなければOK。
2. この台の起動ファイルをダブルクリックする。Aは「Start-Saber-A.command」、Bは「Start-Saber-B.command」。ゲームが表示されればOK。
3. ゲーム画面をクリックする。ゲームのウィンドウが選ばれていればOK。
4. F8を押す。効かなければFn＋F8。「PhoneSaber 運営表示 [F8: 開閉]」の「台: A」または「台: B」がこの台と同じならOK。

同じPCでゲームを2つ起動しません。ゲームを作るアプリ（Unity Editor）も同時に動かしません。
起動用の文字のウィンドウは開いたままにします。ゲームが異常終了すると、5秒後に起動し直します。

1. 技術担当に前回の再起動停止用ファイルが残っていないか確認してもらう。起動ファイル横の `Start-Saber-A.STOP`／`Start-Saber-B.STOP` と `STOP` がなければOK。
2. この台の起動ファイルをダブルクリックする。Aは「Start-Saber-A.bat」、Bは「Start-Saber-B.bat」。ゲームが表示されればOK。
3. ゲーム画面をクリックする。ゲームのウィンドウが選ばれていればOK。
4. F8を押す。「PhoneSaber 運営表示 [F8: 開閉]」の「台: A」または「台: B」がこの台と同じならOK。

同じPCでゲームを2つ起動しません。Unity Editorも同時に動かしません。
起動用の文字のウィンドウは開いたままにします。異常終了した場合だけ、5秒後に起動し直します。
Windowsの通信許可は技術担当が設定します。

### スマホとPCのつなぎ方を選ぶ

| 組み合わせ | 当日使う方法 |
| --- | --- |
| Mac＋iPhone | 事前準備済みなら直接つなぐ方法（P2P）。使えなければ同じWi-Fiにつなぐ |
| Mac＋Android | 同じWi-Fiにつなぐ。※AQUOS実機は未確認 |
| Windows＋iPhone | 同じWi-Fiにつなぎ、必ずPCの番号を手入力。※Windows実機は未確認 |
| Windows＋Android | 同じWi-Fiにつなぐ。※Windows・AQUOS実機は未確認 |

P2Pは、MacとiPhoneを直接無線でつなぐ方法です。事前に技術担当が確認した台だけで使います。
直接つなぐ場合：

1. iPhoneのWi-FiをONにする。ONの表示ならOK。同じWi-Fi名への接続は不要です。
2. iPhoneのインターネット共有をOFFにする。OFFの表示ならOK。

同じWi-Fiでつなぐ場合：

1. PCを末尾に記入したこの台のWi-Fiにつなぐ。接続先の名前が一致すればOK。
2. スマホを同じWi-Fiにつなぐ。PCと接続先の名前が一致すればOK。

### スマホがiPhoneの場合

1. アプリを開く。「Phone Saber Sender」と表示されればOK。
2. 「停止」が出ていたら押す。「通常送信を開始」または「遅延計測を開始」と表示されればOK。
3. 「接続」の「台」でこの台の「A」または「B」を選ぶ。この台と同じ文字が選ばれればOK。
4. P2Pのスイッチを次の表に合わせる。ON／OFFが一致すればOK。
5. 手動欄を次の表に合わせる。古い手入力がなく、この台の接続方法に合えばOK。

| 接続方法 | 設定する場所と内容 |
| --- | --- |
| 準備済みのMacへの直接接続 | 「手動IP（自動発見できない場合のみ）」に古い手入力がないことを確認。「P2P優先 (peer-to-peer Wi-Fi・Mac側 P2P bridge)」をON |
| Macと同じWi-Fiで接続 | 「P2P優先 (peer-to-peer Wi-Fi・Mac側 P2P bridge)」をOFF。自動で見つからないときだけ、上の手動欄にこのMacの番号を入力 |
| Windowsと同じWi-Fiで接続 | 上のP2PのスイッチをOFF。上の手動欄に、このWindows PCの番号を必ず入力 |

手動欄のIPは、PCの接続先を表す番号です。技術担当に現在の番号を確認してください。
古い手入力は自動で見つけた接続先より優先されます。**「台」を選び直しても手入力は残ります。**
自動接続に戻すときは、停止中に手動欄の手入力を消します。iPhoneには保存ボタンはありません。
画面の「Mac:」はWindowsでも同じ表記です。直接接続では「経路:」にPC名が出ます。

6. 「詳細設定」を開く。「接続・出力」と「検出」が表示されればOK。
7. 「接続・出力」の「遅延計測モード」をOFFにする。「通常送信を開始」と表示されればOK。
8. 「検出」の反転設定を確認する。「左右反転」「上下反転」が技術担当の指定と同じならOK。
9. 「起動時に送信を自動開始」をONにする。スイッチがONならOK。
10. 「通常送信を開始」を押す。「停止」に変わり、カメラ映像が動けばOK。
11. 送信先を確認する。直接接続は「経路:」、同じWi-Fiは「送信先:」が、この台のPC名または番号ならOK。

初回の許可画面が出たら、カメラと近くのPCとの通信を許可します。
スマホの接続表示だけでは動作確認は完了しません。次のF8チェックまで行ってください。

### スマホがAndroidの場合

※未確認：AQUOS sense9での以下の実機操作・受信・発熱。

1. アプリを開く。「PhoneSaber — PCへ送信」と表示されればOK。
2. 「停止」が出ていたら押す。「開始」と表示されればOK。
3. 「台（PC と同じ台を指定）」でこの台の「A」または「B」を選ぶ。同じ文字が選ばれればOK。
4. 接続先の「PC:」を確認する。この台のPC名・番号ならOK。違う／見つからない場合は下の手入力手順へ。
5. 明るさなどの数値の下の反転設定を確認する。「左右反転」「上下反転」が技術担当の指定と同じならOK。
6. 「遅延計測モード」をOFFにする。スイッチがOFFならOK。
7. 「起動時に送信を自動開始」をONにする。スイッチがONならOK。
8. 「開始」を押す。「停止」に変わり、カメラ映像が動けばOK。

手入力する場合は停止中に行います。IPv4もPCの接続先を表す番号です。

1. 「PCのIPv4（例: 192.168.1.10）」の欄に、技術担当が確認したこのPCの現在の番号を入力する。番号が一致すればOK。
2. 「手入力を保存（空欄で自動探索）」を押す。「PC: 手入力」と正しい番号が表示されればOK。

自動探索（近くのPCを自動で探す方法）に戻すときは、欄を空にして同じ保存ボタンを押します。
手入力は台選択より優先されます。「台」を変えても、古い手入力は自動では消えません。
カメラの許可を求められたら許可してください。

## 本番前の最終チェック

### F8表示の見方

1. 運営表示が閉じていたら、ゲーム画面でF8を押す。「PhoneSaber 運営表示 [F8: 開閉]」が表示されればOK。Macは必要ならFn＋F8。
2. 点灯した赤・青の剣を両方カメラに映す。スマホの映像に両方の剣が入ればOK。
3. 5秒以上待つ。次の表の値になればOK。表示が下に隠れていたらスクロールします。

画面に出る略語：RED＝赤、BLUE＝青。UDPは動きの情報を送る仕組み、payloadは届いた情報の中身です。
fpsは1秒に撮影・処理した回数です。通常は30fpsで運転します。
pkt/sは1秒に届いた情報の数、sは秒、msは1000分の1秒、nは測った回数です。
p95は、測った値の95%が収まる時間の目安です。小さいほど途切れにくい状態です。

| F8で見る表示 | 正常の目安（赤・青の両方が映っているとき） |
| --- | --- |
| 「台:」 | A台は「A」、B台は「B」 |
| 「UDP受信機:」 | 「RED ON / BLUE ON」。受信機＝スマホの情報を受け取る部分 |
| 「RED UDP 5005」「BLUE UDP 5006」の「pkt/s (直近1秒)」 | 両方とも0より大きい。30fps運転では約30が目安だが、ぴったり30でなくてよい。5005・5006は色別の受け口の番号 |
| 「最終受信:」 | 更新が続き、0.15秒未満が良好。「未受信」や1秒超の警告が続かない |
| 「payload解析:」 | 両方とも「OK」。ただし、実際の剣を正しく見つけた保証ではない |
| 「受信間隔（直近5秒）」 | 「p95」が50ms未満、「最大」が150ms未満、「n」が20以上なら良好。現在の無受信時間も150ms未満 |
| 「判定:」 | 両方とも「良好（間隔のみ）」。最初の「注意（計測中）」は5秒以上待って再確認 |
| 「探索 UDP 5007:」 | Androidで自動探索する場合は「ON」。5007はPCを探す受け口の番号 |
| 「Bonjour:」「P2P bridge:」 | Windowsの「未対応」は正常。Macで同じWi-Fiから自動発見するならBonjourが「ON」、直接接続するならP2P bridgeが「ON」 |
| 「送信元:」「経路:」 | 技術担当が確認した相手・方法と一致。Macの「127.0.0.1」＋「P2P bridge」は直接接続用の中継から届いた表示で正常 |
| 「片道時計差（tsあり）」 | 通常送信では「--（サンプルなし）」でよい。tsはスマホの時刻の印。スタッフはこの値で速さを判断しない |

Bonjourは同じWi-Fi内のPCを見つける仕組み、P2P bridgeは直接接続の情報をゲームへ渡す中継です。
「経路: LAN」は同じネットワークから届いた目安です。送信元の番号だけでスマホを特定はできません。

**暫定の目安（30fps運転）**：「p95」が50ms以上100ms未満、または最大／無受信時間が150ms以上500ms未満なら「注意」。
100ms以上、最大／無受信時間が500ms以上、未受信、解析NGなら「不良」。境界の値は悪い側です。
「注意」「不良」が続く場合は技術担当を呼びます。
剣なし・未検出のときは受信数0や警告が出ることがあります。必ず点灯した両色で確認します。

「スマホとPCのNTP同期を確認済み（片道遅延も判定）」はOFFのままにします。
NTP同期は2台の時計を合わせることです。技術担当が確認した場合だけ使います。
ここで「良好」でも、撮影から画面表示までの全体の速さを保証する表示ではありません。

### 剣の動き・位置・A/Bの確認

1. この台で赤い剣をゆっくり動かす。この台の画面の赤い剣が同じ方向へ動けばOK。
2. この台で青い剣をゆっくり動かす。この台の画面の青い剣が同じ方向へ動けばOK。
3. 左上・右上・右下・左下へ順に剣を動かす。画面全体に届けばOK。ずれる場合は下の位置合わせへ。
4. もう一方の台を確認する。この台の剣を動かしても、もう一方の台の剣が動かなければOK。
5. 剣をカメラの外へ出す。人が映っていても剣を誤って見つけなければOK。
6. F8を押して表示を閉じる。ゲーム画面に戻ればOK。

### 位置合わせ（F7、技術担当と一緒に）

スマホ・箱・立ち位置・反転を変えたら、A・Bそれぞれでやり直します。
反転はiPhoneの「詳細設定」→「検出」、Androidの明るさなどの数値の下。剣を見つけるための数値（閾値）は当日変えません。

1. タイトルまたはメニューで、閉じていたらF8表示を開く。「台:」がこの台ならOK。
2. 「4隅の測定を開始 [F7]」を押す。「1/4: 左上で剣を静止 → F7で1秒採取」と表示されればOK。
3. 点灯した赤い剣の真ん中を、実際に振る範囲の左上で止める。プレイヤーから見た画面の左上側で静止していればOK。
4. 「この隅を採取 [F7]」を押す。「採取中：剣を動かさず、そのまま約1秒待ってください。」と表示されればOK。
5. 約1秒、剣を静止したまま待つ。「2/4: 右上で剣を静止 → F7で1秒採取」と表示されればOK。
6. 右上→右下→左下でも、3〜5を1か所ずつ繰り返す。「4隅を保存し、位置補正をONにしました。剣を動かして届く範囲を確認してください。」と表示されればOK。
7. 両色の剣を動かす。画面全体に届けばOK。

画面上の剣の位置ではなく、実際に振る範囲の隅に合わせます。赤で測った範囲は青にも使われます。
表示が次の隅へ進まなければ、同じ隅で静止して再採取します。失敗が続く場合は技術担当を呼びます。

## 営業中にやること・見るもの

1. お客さんを所定の床表示へ案内する。プレイ範囲に他の人が入っていなければOK。
2. スマホのアプリを画面に出したままにする。カメラ映像が動いていればOK。
3. お客さんの交代時にスマホの発熱表示を見る。「正常」が目安。「高い」「危険」や注意表示なら下の対処へ。
4. 電池表示を見る。「充電中」または「満充電」で、電池残量が減り続けていなければOK。
5. 剣の動きに違和感が出たらF8を開く。点灯した両色で最終チェックの表に戻ればOK。

fpsは1秒に撮影・処理した回数です。通常30fpsのとき、開始3秒後から21fps未満になると注意が出ます。
iPhoneはカメラ・処理、Androidは解析の値を見ます。iPhoneで60fpsを指定した場合は42fps未満が注意です。
発熱表示は温度の数字ではなく、スマホが判断した状態です。「やや高い」は通風と電池をこまめに見ます。

アプリを画面に戻すと送信が自動で再開することがあります。再開しなければ開始ボタンを押します。
「停止」を押した後は、画面に戻すだけでは再開しません。ただし自動開始がONなら、次のアプリ起動時に開始します。

## 困ったとき

各症状の1→2→3を順に行います。**直らなければその台の受付を止め、技術担当を呼びます。**
技術担当が不在なら運営責任者を呼びます。症状・A/B・F8の表示を伝えてください。

### 剣が動かない

1. スマホのアプリを画面に戻す。カメラ映像が動けばOK。ロック中は先に解除します。
2. 自動で再開しなければ開始ボタンを押す。iPhoneは「通常送信を開始」、Androidは「開始」。「停止」に変わればOK。
3. F8表示を確認する。点灯した両色で「RED ON / BLUE ON」、受信数が0より大きく「payload解析: OK」ならOK。

直らなければ技術担当へ。受信機が「停止」の場合は、同じPCでゲームなどが二重起動していないか調べてもらいます。

### 剣がガタガタする・向きが逆・位置がずれる

1. スマホの固定とレンズを確認する。揺れず、剣が映っていればOK。
2. F8の「受信間隔（直近5秒）」を確認する。点灯した両色で「判定: 良好（間隔のみ）」なら通信の間隔はOK。
3. 技術担当と「剣の動き・位置・A/Bの確認」をやり直す。反転や位置合わせ後、両色が画面全体で正しく動けばOK。

直らなければ技術担当へ。照明・背景の誤検出・発熱も調べてもらいます。当日、認識用の数値を試しに変えません。

### スマホが熱い・fpsが下がる・電池が減る

1. 箱を開ける。空気の通り道ができればOK。
2. 給電を確認する。「充電中」または「満充電」と表示されればOK。
3. 「危険」が続く場合は「停止」を押す。iPhoneは開始ボタンに戻り、Androidは「開始」「停止中」と表示されれば停止できています。

改善しなければ技術担当へ。送風・排熱からの移動・冷却または予備スマホへの交代を頼みます。充電中でも熱くなることがあります。

### ゲームが落ちた・画面が消えた

1. 5秒待つ。台別起動ファイルからの異常終了なら、ゲームが起動し直せばOK。
2. 戻ったゲームで最終チェックを行う。台・両色の受信・画面の動きが正常ならOK。
3. 落ち続ける場合は、その台の受付を止める。新しいお客さんが入っていなければOK。

戻らない／繰り返す場合は技術担当へ。起動し直す監視の停止・記録の保存・予備PCへの交換を頼みます。
正常な終了操作では自動再起動しません。Unity Editorでの試運転も自動再起動しません。

### 別の台につながった

1. スマホの「停止」を押す。開始ボタンに戻ればOK。
2. スマホの台を正しい「A」または「B」にする。F8の「台:」と同じならOK。
3. 手入力の番号を確認する。使う場合は正しいPCの現在の番号、使わない場合は手入力を解除できていればOK。

再開は該当スマホの準備手順から行います。Androidの入力変更は「手入力を保存（空欄で自動探索）」で確定します。
PC側の台が違う／直らない場合は技術担当へ。正しい台の起動ファイルで起動し直してもらいます。
**台の設定は接続先を選ぶ目印です。別台から来た情報を拒否する仕組みではありません。**

### PCが見つからない・Wi-Fiを変えてから動かない

1. スマホの「停止」を押す。開始ボタンに戻ればOK。
2. PCとスマホのWi-Fi名を確認する。同じ台の指定されたWi-FiにつながっていればOK。
3. 手入力の番号を確認する。今の接続で使うPCの番号ならOK。Windows＋iPhoneは必ず手入力します。

再開は該当スマホの準備手順から行います。直らなければ技術担当へ。
学校のWi-Fiが機器同士の通信を止めている場合は、PCが用意した予備Wi-Fiへ切り替えてもらいます。
切替後はPCの番号が変わる場合があるため、古い番号を使い続けません。
Mac＋iPhoneの直接接続の不調も、技術担当と同じWi-Fiへ切り替え、P2PのスイッチをOFFにして試します。

### カメラ映像が止まった

**iPhoneの場合**

1. アプリを画面に戻す。映像が動き始めればOK。
2. 自動でやり直すまで最大30秒ほど待つ。映像が戻ればOK。
3. 表示された「カメラを再開」を押す。映像が戻ればOK。

**Androidの場合**

1. アプリを画面に戻す。自動でやり直して映像が動けばOK。
2. 戻らなければ「停止」を押す。「開始」「停止中」と表示されればOK。
3. 「開始」を押す。映像が動けばOK。

直らなければ技術担当へ。カメラの許可と予備スマホを確認してもらいます。復帰後は最終チェックを行います。

## 終了の片付け

A台・B台それぞれで行います。不具合があった台は、終了前にF8の「イベントログ:」の場所を技術担当に控えてもらいます。

1. スマホの「停止」を押す。iPhoneは開始ボタンに戻り、Androidは「開始」「停止中」と表示されればOK。
2. 「起動時に送信を自動開始」をOFFにする。スイッチがOFFならOK。
3. F8表示が開いていたらF8で閉じる。ゲーム画面に戻ればOK。
4. ゲームのタイトル画面の右下にある×の終了ボタンを押す。ゲームと再起動の監視が終了すればOK（技術手順書のQuit＝正常終了。文字のボタンがある画面では「QUIT」）。
5. 不具合があった台の記録を技術担当に保存してもらう。イベントログのファイルと古い4本、起動ファイル横の記録が保存できればOK。
6. Macで追加の診断用ウィンドウが動いていたら技術担当に終了を頼む。記録の受取・確認が終わり、終了できればOK。
7. スマホ・箱の熱を確認する。冷めてから機材を収納できればOK。

監視だけ止める場合は起動用の文字のウィンドウでCtrl＋C
（Windowsは終了の問いに「Y」）。技術担当が停止用ファイルを置いた場合は、次回起動前に削除してもらいます。
停止用ファイルは、今動いているゲームを強制終了するものではありません。

## 付録：用語・連絡先欄

| 用語 | 意味 |
| --- | --- |
| IP／IPv4 | PCの接続先を表す番号。Wi-Fiを変えると変わる場合がある |
| P2P／P2P bridge | MacとiPhoneの直接無線接続／その情報をゲームに渡す中継 |
| LAN／Bonjour | 同じ場所のネットワーク／その中のPCを見つける仕組み |
| UDP／payload | 動きの情報を送る仕組み／届いた情報の中身 |
| fps／pkt/s | 1秒の撮影・処理回数／1秒に届いた情報の数 |
| ms／p95／n | 1000分の1秒／95%の値が収まる時間の目安／測った回数 |
| NTP同期／ログ | 機器の時計を合わせること／不具合を調べるための記録 |
