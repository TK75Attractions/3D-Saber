# タイトル画面の比較候補

3人のAI専門家役が文字・空間・動きを分担して制作し、互いの案をレビューした比較版です。これまでの改修に加えて、3種類のタイトルをゲーム内で切り替えられます。

Titleシーンを再生して、数字キーまたはテンキーの **0・1・2・3** を押してください。初期表示は0。選んだ案はアプリを終了するまで維持されます。切れるキューブ、クリック、Enter/Spaceによる開始操作は共通です。

| キー | 候補 | 比較したい点 |
| --- | --- | --- |
| 0 | 前回の改修 | 細い専用字形、3段ロゴ、赤青のレールと床 |
| 1 | A：切断面のある文字 | 太い直立文字に斜めの切れ目を入れた、工業的な構成 |
| 2 | B：光のゲート | 2段の大きなロゴと、奥行きを持つ3層の門 |
| 3 | C：刃と残光 | 細い横長文字を右にずらし、左右の刃にゆっくり残光を流す構成 |

## 制作と確認

ロゴは必要な文字の輪郭を個別に定義したUIメッシュで、既存フォントや生成画像は使っていません。下部の説明文は増やさず、開始ノーツのまわりを空けています。

全4案について1080p・720pの描画、見えているノーツの位置からのクリック、切断、選曲画面への遷移が成功しました。実機センサー、物理キーボードによる切り替え、プロジェクター投影の確認は含みません。

再確認には検証用コピーのUnityをバッチ起動し、`-executeMethod TitleDesignCapture.Render -titleAllConcepts -titleOutput <出力先>`を指定します。各案の画像と確認結果を保存します。
