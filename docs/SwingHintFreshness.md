# 振りの方向情報が古くなったときの判定

以前は、受け取った振り情報を後で処理すると、その処理時点からもう一度有効期間を数えていました。画面処理が遅れたときに、古い振りが新しい振りとして方向判定を補助してしまう状態です。

受信した時刻を保持し、受信からの経過時間で失効するように変更しました。既定の有効期間は0.30秒のままです。受信から処理まで0.12秒かかった場合、その後に残る期間は0.18秒になります。ゲームの一時停止や速度変更で延長されません。

接続状態の通知や入力コンポーネントの無効化・再有効化でも、前の方向情報を持ち越さないようにしました。同時配置されたノーツは同じ判定内で同じ情報を使うため、1回の振りで複数を切る動作は維持します。

この変更は古い方向情報の再利用を直すものです。タイミング幅、必要な速度、方向の許容角度は変更していません。左右センサーの識別や、乱振りで成功するすべての原因を解決したものではありません。

実機での振りやすさとプロジェクター上での体感は別途確認が必要です。Unityの自動テストでは、受信・配送の時刻差、期限の境界、停止・再接続、同時切り、通常切り・ロング・左右判定を確認しました。関連するEditMode 89件と、実際のUDP受信を含むPlayMode 5件が成功しています。
