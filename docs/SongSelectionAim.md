# 選曲画面の照準操作

2026-09-19。ユーザーが提案・採用した「銃の照準を1秒かざすと、発射音とともにノーツが砕けて選択する」操作。

## 操作

- 棒1の追跡位置、またはマウスで照準を動かす。選曲画面では剣の表示・通過による切断を使用しない。
- 曲・難易度・START・タイトルへ戻る・判定調整・上下の曲送りへ1秒合わせると発射する。蓄積は照準のリングとノーツの明るさで示す。
- 別の項目へ移るか、対象から外れると蓄積を取り消す。対象端の小さな手ぶれには画面の表示倍率に応じた余裕を設ける。
- 発射後は、そのときの対象の画面領域から0.12秒離れるまで再受付しない。対象の再出現・曲一覧の移動・別の項目が下に来ることだけでは再発射しない。
- 発射音、衝撃波、12個の立体破片を表示する。通常のボタンは0.18秒の破砕表示後に操作を確定する。曲送りは発射時に移動する。
- 元のクリック・キーボード・ゲームパッド操作も使用できる。通常クリック後の置きっぱなしは再発射しない。発射演出中に別の曲や難易度を選ぶと古い予約を取り消す。

## 入力断と画面遷移

追跡入力が0.2秒以上途切れたら蓄積を止める。止まった追跡位置を残して発射したり、以前のマウス位置へ勝手に切り替えて蓄積を始めたりしない。追跡からマウスへ切り替える場合はマウスを動かす。入力源の切替・フォーカス喪失・画面遷移でもため直す。0.2秒を超える長いフレームも蓄積へ加算しない。

## 範囲と資源

変更は選曲画面のみ。タイトルの開始ノーツ、ゲーム内の判定・譜面、判定調整の操作は維持する。EFFECTS／PROJECTORボタンは削除したまま。描画設定の保存値とF4も維持する。

照準と衝撃波は再利用するUIメッシュ。破片は上限12個の一つのメッシュ、素材一つ、発射音一つを繰り返し使い、シーン終了で解放する。保存済みの演出軽減設定では破片を6個にする。

`SongSelectAimTrackerTests` は1秒、対象切替、入力断、再発射防止、一覧移動、手ぶれ、長いフレームを確認する。実シーンの操作テストでは難易度・曲送り・START、通常クリック、追跡位置の入力断、画面遷移、音・素材・メッシュの繰り返しと解放を確認する。追跡入力のテストには人工座標を使用し、実機センサーでの照準位置・手ぶれの体感は別途確認が必要。

2026-09-23: 照準が見にくいとの指摘で、照準を半径27→36px、蓄積の帯を3→6px、暗い縁取りを全周・目盛り・中心点に追加し、中心を塗り円にした(`SongSelectAimGraphic.ReticleRadius/RingWidth`)。発射の衝撃波と放射線にも暗い下敷きを付けた。動作(1秒・解除・再発射)は変更していない。
