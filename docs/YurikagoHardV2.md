# 揺籠 Hard 改訂版 — Lv.9

Normalは好評だったため一切変更せず、Hardだけを組み直した。Easyと互換用chart.jsonも変更しない。引き続き、参考譜面はElDoradoのみ。

## リズムの変更

初版は、3連の1・2個目を置いて3個目を休む「短い間隔→長い間隔」の2打が多かった。さらに、短いロングが小節ごとの同じ位置に現れることで、繰り返しの印象が強くなっていた。

- その2打パターンは **65拍分→4拍分**。ノーツがある拍に占める比率は約39.2%→2.5%。これはオブジェクトの出現タイミングを比較した指標であり、ロングの実際の切り方までは含まない。
- 3連を丸ごと取るフレーズ、1拍休んで返すフレーズ、拍の頭を抜いた食い込み、同時切りの応答を組み合わせた。
- 3〜5打の短い連打を13箇所に配置。「3打→間→1打」「1打→3打」「4打」「5打」を区間によって変える。
- 最短間隔は約174ms。同じ手では約349ms以上の回復時間を残し、速い連打は中央寄りの小さな弧に配置した。
- 半パルスへ追加した19個の打点は、音源のスペクトル変化量を±45msの範囲で再確認。弱い候補は採用せず、フィルや細かい音がある位置を使った。完全な楽器分離・歌詞採譜ではない。
- 短いロングを毎小節置く形をやめ、持続音や曲が引く場所に絞った。ロングは38個→18個。
- 2:12前後の静かな部分と2:45〜2:47の余韻は残し、全編を連打で埋めない。

## 確認と使い方

選曲画面で「揺籠」→「Hard」を選ぶ。新しい譜面はLv.9として表示される。すでに選曲画面を開いたままの場合は、いったん入り直す。

時刻とbeatの一致、配置範囲、同時切りの分離、同じ手の回復時間、移動速度、ロングとの重なり、曲末へのはみ出しをチェック済み。実機での最終的な手触りの確認は別途必要。

音合わせプレビューは仮想操作の効果音ミックスで、実プレイ録音ではない。ロングは指定時間内に均等に切る想定。全曲版・0:50〜1:15版・2:10〜2:50版を制作時の `Outputs/YurikagoCharts/HardV2/` に保存する。

初版Hardのバックアップは `Tools/ChartDesign/Backups/Yurikago-hard-before-v2-20260905/`。制作スクリプトは `build_yurikago_hard_v2.py`（先に元の音源解析結果が必要）。通常の `build_yurikago.py` は初版の生成用なので、Hard改訂版の再生成には使わない。
