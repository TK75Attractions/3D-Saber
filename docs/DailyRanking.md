# リザルトの本日ランキング

通常プレイの終了後、リザルト下部に「本日 ○位」「○人中」を表示する。1プレイを1人とした延べ人数であり、個人を識別した実人数ではない。比較範囲はこの端末・同じ曲・同じ難易度・終了日のプレイ。「この端末・同じ曲」という画面内の説明はユーザー指定で削除。ネット接続・アカウント・追加パッケージは不要。

## 導入

- `DailyRankingStore`、`DailyRankingPresentation`、`DailyRankingWheel`と、それらを呼ぶ`GameSession`・`GamePlayManager`・`ResultSkin`・`ResultReveal`が必要。シーンの手動配線やInspector設定は不要。
- `GamePlayManager.FinishWithAchievements`でコンボボーナスを精算してから一度だけ登録する。途中終了、キャリブレーション、リザルトシーンの直接プレビューでは登録しない。
- `GameSession.ResetResult`で次のプレイ用IDと結果をリセットする。結果画面は保存済みスナップショットを表示し、再表示やスキップでは再登録しない。
- 導入後の完了プレイから集計を開始する。既存の歴代ベスト5は全プレイを保持していないため、そこから当日順位を推定・移行しない。歴代ハイスコアの保存領域は維持する。
- 配布する場合は、このソースを含めて通常どおりUnityからゲームをビルドする。既存の配布済み実行ファイルは自動更新されない。

## 集計ルール

- 得点降順。同点は同順位（100点・100点・90点なら1位・1位・3位）。次の順位までの表示は、直上の得点を**1点上回る**ための必要点数。
- 0点の完了プレイも含め、当日分を全件保持する。歴代ベスト5の圏外でも実際の順位を計算できる。
- 端末の現地日付が変わった後の最初の登録で、その曲・難易度の前日分を当日分に置き換える。日本の会場ではPCのタイムゾーン・時計を日本時間に合わせる。
- 同じ日にアプリを再起動しても維持する。日付をまたいで結果画面を開いている場合は終了時の順位・日付を維持し、再登録しない。
- 保存先は`PlayerPrefs`の`dailyRanking_v1_...`キー内のJSON。読み込み不正時は「順位を取得できませんでした」とし、不正データを空の1位で上書きしない。
- 同率1位と単独のトップ更新を区別する。本日最初の1件には「本日最初の記録！」を出す。

## 演出

- リザルト開始2.42秒：ランキング帯が登場。
- 1～3位：2.72秒から背景を暗くし、中央に「本日のランキング」「○人中」と大きな数字ホイールを表示。クリック音とともに数字が回転し、徐々に減速する。
- 4.30秒でホイールが実際の順位に停止。数字を大きく出し、4.48秒に重い「デン！」という衝撃音・局所的な光・リングとともに着地する。1位は金、2位は銀、3位は銅。
- 5.65秒で特別演出を閉じ、下部の順位・人数表示とBACKへ戻る。4位以下は従来の2.78～3.08秒の着地と短い和音、3.58秒からBACKの進行を維持する。
- 既存のクリック／キーによるスキップで即座に確定表示へ移り、回転音と衝撃音も止める。
- LOW設定では特別ホイールを出さず、ランキング帯の移動・数字の拡縮・光の走査を省いた通常のフェード表示とする。画面全体のフラッシュは使わない。
- `ResultReveal`の`Time.unscaledDeltaTime`による共通の時計を使い、画面遷移中は待つ。スキップ時に効果音を遅れて鳴らさない。

## 調査した公式資料（2026-09-30）

1. [Unity Leaderboards: Resets](https://docs.unity.com/en-us/leaderboards/concepts/resets) — 期間ランキングは日次などの境界で別集計にする。今回も歴代ベストとは独立した保存領域とした。
2. [Unity Leaderboards: Unity Dashboard](https://docs.unity.com/en-us/leaderboards/configuration/unity-dashboard) — オンライン方式では環境ごとのボード、ソート順、更新方針、定期リセットを設定する。現状の端末内運用には通信・認証依存を追加しない方式を採用。
3. [Unity 6.3: JsonUtility](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/JsonUtility.html) — Unityが対応するフィールドをJSONとして保存する方法。辞書ではなくSerializableクラスとListで実装。
4. [Unity 6.3: PlayerPrefs](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/PlayerPrefs.html) — アプリの再起動をまたぐ端末内の永続化。Windowsではレジストリで、Editorとビルドの保存先は別になる。既存ハイスコアと同方式を使う。
5. [Unity 6.3: Time.unscaledDeltaTime](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Time-unscaledDeltaTime.html) — timeScaleに依存しない時間差。結果演出はゲーム速度から独立させる。

複数PCを共通集計する場合は別途サーバー集計が必要。Unity Leaderboardsなどを使い、参加者またはプレイの識別方針、共有する曲・難易度、日付境界の時刻とタイムゾーンを決める。1台の共通ログインに全来場者の得点を送ると、プレイヤー単位の更新方式では1件に集約されるため、今回の延べプレイランキングをそのまま置き換えることはできない。
