# 切断の手応えとロングの蓄積感

2026-10-03。ユーザーが選んだ案1・3・4を、同時進行の変更に統合する。

- **案1・判定別の切断音**: Claude側で追加済みの `JudgmentSfx` と `Saber_NoteCut_Perfect/Great/Good/Bad` をそのまま使用する。音量・曲時計・振動の通信は変更しない。
- **案3・ロング**: 同梱音または指定音の途中打撃を、原音から最大4半音まで進行率に応じて上げる。4声を独立させ、左右のロングが同時に進んでも再生中の別の音の音程を変えない。合成音フォールバックは既存の上行音階を維持。最終打は既存の完了音／金専用音だけを鳴らす。
- 途中のひびは受理された打撃位置と方向に沿って残り、完了に近づくと既存の傷も太く長くなる。途中に成功リングを出さず、ノーツの本体・判定形状は変えない。
- 最終打の二片は切断面から左右へ開き、両方とも振った先へ進む。ロングでは分離を1.22倍、最終判定のアクセントを標準表示だけ1.18倍にする。細片も振り方向に沿った扇状に飛ぶ。
- **案4・斬撃の方向**: 斬撃線を先細りにし、寿命を75msから110msへ変更。切断点から振り方向へ抜ける移動を強め、リングの幅・濃さと白い十字の横成分を抑える。Perfectの虹リング・光片・切断片の発光、Great/Goodの段階差、Bad/Missの追加演出なしを維持。
- LOWは斬撃の伸びを60%にし、ロング最終打の拡大を適用しない。従来の火花数・リング数・フラッシュ抑制も維持。

## 同時進行の変更との境界

今回の実装で変更する既存コードは `LongNoteCutSfx.cs`、`CuttableNote.cs`、`GameplayCutFeedback.cs` の3ファイル。
Claude側で追加された `FlowDebris`、ノーツの進行速度を残す処理、軽い重力、回転、短い破片寿命、およびPerfect発光の予約処理を統合して保持する。`SlicePieceDecay` の共通初速1.9倍は維持する。
メニューの `DirectionVisualOnly` は従来の二片の飛び方を維持する。シーン・譜面・判定条件・採点・カメラ・入力・背景演出・共有音源はこの実装では変更しない。

## 検証

`CutFeelTests` は8方向の切断片、斬撃メッシュの進行方向、ロングのひびの成長と再利用、最終打だけの細片、音程上限を確認する。
`CutFeelAudioPlayTests` は実際のノーツ通知からの独立再生、最終打の二重再生なし、譜面交換・無効化・破棄時の音声と購読の回収を確認する。
併せて既存の判定音、ロング採点、切断、Perfect発光、演出寿命・所有権のテストを実行する。描画確認は実Gameシーンの標準／LOWに人工入力を送る。
実機センサー、振動機器、会場スピーカーでの体感確認は別途必要。
