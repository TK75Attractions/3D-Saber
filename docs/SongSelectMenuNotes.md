# 曲選択：斬れるメニューノーツ

2026-09-19。対象は画像の曲選択画面。ユーザー回答により、クリック・キーボード操作も維持する。

## 参考にしたゲームと採用内容

- [Fruit Ninja Classic / Halfbrick](https://www.halfbrick.com/games/fruit-ninja-classic)：対象そのものを斬る単純な操作。曲選択でも同じ立体ノーツを斬って機能を実行する案に採用。
- [Fruit Ninja VR 2 開発者インタビュー / GameAnalytics](https://www.gameanalytics.com/blog/fruit-ninja-dev-talks-porting-to-vr)：操作できる実物にUIを結び付けること、単純で直感的な操作、音の案内。立体ノーツと近接ラベル、短い切断音に応用。VR向けのHUD廃止は、本作の投影画面にはそのまま適用しない。
- [Beat Saber / 開発元のSteam説明](https://store.steampowered.com/app/620980/Beat_Saber/)：ビートを斬る直感的な遊びと明瞭な視覚表現。本編のノーツと同じ割れる立体形状を使い、操作を覚え直す負担を減らす。メニューの難易度色は役割表示で、使用する手や斬る方向の制限にはしない。
- [Synth Riders / 開発元更新履歴、2020-08-21](https://store.steampowered.com/news/posts/?appids=885000&enddate=1602869545&feed=steam_community_announcements)：Forceモード内で全ノーツの操作方式を揃えた変更を確認。「一部はかざす、一部は斬る」という混在を解消する根拠として採用。

他作品の正確な速度閾値を移植したわけではない。以下は3D-Saberの既存曲送り判定を基準にした本作向けの設計。

## 操作仕様

- START、3難易度、タイトルへ、判定調整、PROJECTOR、曲一覧に立体ノーツを配置。既存の上下曲送りノーツも速度と誤操作防止を揃える。
- ノーツを通過する斬撃が3 Unity座標単位/秒以上のときだけ受理。実機のm/sを表す数値ではない。
- どの方向、どちらのセーバーでも可。静止・低速の接触・1秒かざす操作では発火しない。
- 共通の0.7秒クールタイム。斬った操作ノーツは0.8秒後に復帰。曲送りの既存2秒復帰・クールタイムは維持。
- ノーツ本体で速度条件と有効状態を再確認し、判定処理以外の経路でも低速で破壊できないようにする。
- 切断後0.12秒だけ演出を見せてから実行。無効なSTARTや見えない曲行は斬れない。
- マウスクリックとキーボードの操作は継続。マウスでの素振りも既存通り利用できる。
- 選曲画面のボタン形状・余白を統一。難易度は色と文字の両方で選択中を示す。
- 譜面・音源は変更しない。
