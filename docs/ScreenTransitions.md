# 画面遷移

画面を離れる操作は `ScreenTransition.Load` を通す。タイトルの終了操作は `ScreenTransition.Quit` を使う。

| 経路 | 演出 |
| --- | --- |
| タイトル → 選曲 | 4種類の背景それぞれの既存の前進演出 → 共通の暗転 → 選曲を表示 |
| タイトルの背景切り替え | 赤・青の斜めの光と暗転 |
| 選曲 → プレイ | 赤・青の斜めの光と暗転 |
| 選曲 → 判定調整 | 緑・青の斜めの光と暗転 |
| 選曲 → タイトル | 傾きを逆にした赤・青の光と暗転 |
| 判定調整 → 選曲（保存・破棄） | 戻る演出 |
| プレイ終了 → 結果 | 金・青の光と暗転 |
| 結果 → 戻り先 | 戻る演出 |
| アプリ終了 | 戻る演出の後に終了。Editorでは幕を開いて操作を戻す |

通常は退出0.42秒・登場0.38秒。タイトル開始は既存の0.92秒を維持する。
描画の準備が済むまで不透明な幕を保持し、カウントダウンと結果・タイトルの登場演出は幕が開いてから進める。
時計には非スケール時間を使い、`Time.timeScale` 自体は変更しない。

遷移中は重複した移動要求を受け付けず、EventSystem、セーバー判定、画面固有のキー操作を止める。
選曲ノーツの切断後に予約された別の操作も取り消す。新しいシーンの入力は登場演出後に戻し、
元から無効なEventSystemは有効化しない。画面名が不正な場合は現在の画面を保つ。

`ScreenTransitionPlayTests` は実シーンで全タイトル、ボタンとノーツによる帰還、判定調整の保存／破棄、
プレイ開始と終了、結果からの帰還、同一シーン再読み込み、一時停止、重複要求、途中破棄、不正な画面名を確認する。
`-transitionCapture <directory>` を付けると、描画した途中状態のPNGも保存する。
