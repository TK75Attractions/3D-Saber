# 選曲画面の右手操作案内

選曲画面に入った直後に「右手で照準を合わせてね！」を表示する。白い人体模型が赤い右手でセイバーを持ち上げるアニメーションを一周（5.2秒）表示して一旦閉じ、入場から10秒経っても操作がなければ再び案内を表示する。再案内は操作するまで5.2秒で繰り返す。保存済みの模型をそのまま撮影した透過2Dコマ画像で表示する。

- 入場時も再案内も、操作可能な同じ対象を0.4秒狙い続ける、クリック、スクロール、キー、ゲームパッド、曲・難易度の変更で案内を終了する。操作後はその選曲画面では再表示しない。再入場時には再び最初の案内から表示する。
- 照準の移動だけでは操作とみなさない。手ぶれ、ゆっくりしたずれ、持ち直しがあっても10秒で案内する。マウスも同じ判定とし、静止する必要はない。対象を短く横切るだけでは終了せず、対象の変更・照準が外れる・入力断で狙っている時間を数え直す。0.4秒の判定は対象を決定する長押し時間（1秒／2秒）とは独立する。
- 画面遷移中・フォーカスがない間は時間を数えず、案内も表示しない。通常の100秒カウントダウンや試聴は既存のまま動く。
- 案内はレイキャストを遮らない。表示中でもそのまま曲や難易度を狙える。背中側から見せるため、本人の右手が画面でも右側に見える。

## 2Dアニメーション素材

`Assets/Resources/UI/SongSelectAnime/RightHandGuide.png` は3072×2048の透過画像で、512×512の24コマを横6×縦4に配置する。以前の3D版の `Tools/SongSelectHuman/RightHandHuman.blend` から、同じ模型・ポーズ・配色をBlenderで直接書き出した。同じ固定カメラと照明を使い、コマごとに体形や足元の位置が変わらない。再生成は `Tools/SongSelectMannequin/BuildAtlas.ps1` と `render_frames.py` を使う。旧人物イラストの生成指示は過去資料としてTools内に残っているが、現在の素材の生成には使用しない。

開始時は腕を下げ、約1.1秒かけて24コマで上げる。照準を合わせる姿勢を保ち、同じコマを逆にたどって約0.9秒で腕を戻す。加減速は書き出した動作に含まれる。表示されていない間は進めない。LOWでも同じ説明動作を維持する。

`SongSelectGuideModel` は既存の呼び出しとの互換性のため名前を保っているが、実装は2DのUI描画のみ。表示時にPNGを読み込み、画像の参照範囲を切り替える。3D人体・専用カメラ・RenderTexture・照明・コライダーは生成しない。画像は共有リソースとして扱い、UI破棄時に直接破棄しない。

参考にした3D素材は `Tools/SongSelectHuman/Reference3DAssets/SongSelectHuman`、Blender編集元は `Tools/SongSelectHuman/RightHandHuman.blend` に保存する。参照元は [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) のCC0モデルで、元のライセンスも素材とともに保持。これらはAssets外の参考資料とし、案内の実行には使用しない。

## 検証

`SongSelectIdleStateTests` は入場時の一回表示、10秒での再案内、初回操作、再入場、フォーカスを確認する。`SongSelectIdleGuidePlayTests` は実シーンへの入場直後の表示と再案内、手ぶれ・ずれ・持ち直し中の表示、短い横切り・対象変更・入力断、継続した照準での解除と選択、全24コマとループ、2D画像の切り替え、追加カメラを生成しないこと、透過レイキャスト、非表示中の停止を確認する。720p・1080p・LOW設定でもプレビューを確認する。センサー実機とプロジェクターでの見え方は別途確認する。
