# Zero -狂奏曲-：作者版Hardからの改作

2026-10-13。ユーザーの「自分のHardを魔改造し、非常に長い同時ロングと適度な同時切りを残す」という依頼に対応。曲ID `製作中` のHardを、作者版の打点とロングを核に再構成した。

## 残した見せ場

3組の同時ロングは開始時刻、長さ、切断回数、座標、色、方向を完全に維持した。下表の開始秒は音源上の時刻（`time + offsetMs`）。

| 開始秒 | 左の長さ・切断回数 | 右の長さ・切断回数 |
| --- | --- | --- |
| 34.360 | 4.926333秒・11回 | 4.918333秒・11回 |
| 88.860 | **18.406333秒・44回** | **21.677秒・44回** |
| 148.235 | 3.750秒・9回 | 3.750秒・9回 |

このゲームのロングは、表示された回数だけ繰り返し切るノーツ。約89秒からの超ロングが主役になるよう、この間に別のノーツを追加して両手を奪う配置を整理した。片方の超ロングが終わっても、もう片方の終了まで休ませる構成にした。

## 改作の狙い

- 導入は上下の応答、18秒付近からは内側へ上る階段、40秒付近からは内外へ広がる動きにした。
- 同時切りの連続は左右交互へ展開し、同時切りはアクセントとして通常19組、同時ロング3組を残した。
- 片手ロングの間にもう一方で応答し、静かな区間で密度を下げ、終盤は方向切りと左右への広がりを戻した。
- 作者版の単発打点を優先した。45ms以内に分かれた左右ペアは中心時刻にそろえ、追加打点は指定した空き区間の音の立ち上がりを照合した。全体の打点を一律に格子へ丸めてはいない。

参考にした公式の操作・配置資料と、このゲームへ取り入れた要素:

| 参考 | 取り入れた要素 |
| --- | --- |
| [Beat Saber公式エディター：ノーツ配置](https://beatsaber.com/documentation/placing-notes/index.html) | 色・方向・位置の組み合わせと、次のノーツへつながる手の動き |
| [maimai公式：遊び方](https://maimai.sega.com/play/howto/) | 同時入力をアクセントにする構成、内外へ動く軌道の発想 |
| [CHUNITHM公式：遊び方](https://chunithm.sega.com/play/) | 短い入力と長い入力の対比、左右で役割を分ける構成 |

これらは配置を考える参考であり、他作品の譜面データの移植ではない。このゲームにないスライド・AIR判定などは追加していない。

## データと再生成

262ノーツ、ロング内の切断を含め404判定、ロング14本、方向付き157ノーツ。BPM98、`offsetMs:110`、`beatZeroMs:-90`、14区間の変拍子、`displayLevel:0`（自動算出）を維持。Easy・Normal・互換譜面・音源・ステージ演出は変更していない。

改作前の作者版は [authored-hard.json](../Tools/ChartDesign/Seisakuchu/ZeroHardRemix/authored-hard.json) に保存した。SHA-256は `b069bd8920a3865245e0302d7463c0bbca700a12fb7959b9c176f7ba88799b99`。各ノーツの元データとの対応と追加打点の音響照合は同じフォルダーの `provenance.json`、配置検証は `validation.json` に記録した。

Python・NumPy・SciPy・ffmpegを用意し、リポジトリのルートから実行する。生成先は本番とは別のフォルダーにする。後日手編集した現行譜面を、この生成結果で上書きしないこと。

```powershell
python Tools/ChartDesign/Seisakuchu/ZeroHardRemix/analyze.py --audio "Assets/StreamingAssets/Songs/製作中/audio.mp3" --output "Temp/ZeroHardRemix/features.npz"
python Tools/ChartDesign/Seisakuchu/ZeroHardRemix/remix.py --features "Temp/ZeroHardRemix/features.npz" --output "Temp/ZeroHardRemix/candidate"
```

## 検証

Unity 6000.3.9f1の関連EditModeテスト50件成功。同時ロング3組の全フィールド保持を、本編の譜面ローダーで確認した。生成時にはヘッダーの一致、全ロングの各切断、座標、音源長、同じ手の回復時間、矢印への進入と振り抜きを検査した。同じ手の切断間隔は最短約428ms。

本編Gameシーンの自動プレイ録画も完了し、Resultシーンまで到達した。記録された全404切断の時刻（1ms単位）・位置・ロング内の連番と回数が譜面と一致した。左右44回の超ロングも合計88切断すべて確認。集計は `autoplay-validation.json` に保存した。これはスクリプトで判定を投入する本編動作確認であり、センサー入力や実際の手振りのテストではない。実行後は撮影用スクリプトを削除し、ユーザーのシーン・ウィンドウ配置・設定・スコアを復元した。

動作経路の検査は、金ノーツを左右の位置に対応する手で切る経路に基づく。金ノーツのすべての手の選択や、実機での振り心地を保証するものではない。
