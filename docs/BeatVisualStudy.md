# セイバー・切断・Pulse Arrayの視覚設計

2026-09-17。Beat Saberの公式映像をブラウザーで停止・コマ送りして観察した。下記の時刻は今回確認した箇所。映像から分かる見え方と、公式照明ドキュメントを参考に、本作の正面投影・左右セイバー用の形状を実装した。

## 観察した資料

- [The Master / OST 7 公式プレイ映像](https://www.youtube.com/watch?v=l7Wv4QRNti0) 14秒・28秒。暗い中央にノーツを置き、外側の折れた照明と大きな面で奥行きを作る。刃は明るい芯と色の縁を持ち、切断直後は局所的な光と細い火花が見える。
- [Daft Punk Music Pack 公式トレーラー](https://www.youtube.com/watch?v=TZyKEdxda84) 10秒・20秒。遠近の照明を層に分け、同じ空間でも冷色と暖色、光る領域を切り替えて展開を作る。中央の通路を装飾で埋めない。
- [Battery / Metallica Music Pack 公式プレイ映像](https://www.youtube.com/watch?v=nW74rHqHuO4) 12秒・24秒と、その後4コマ。天井の骨組みと側面の照明を奥へ反復。刃全体の薄い帯状の残光、振った方向へ伸びる細い火花、離れていく切断片を観察した。
- [公式 Group Lighting Event System](https://beatsaber.com/documentation/the-group-lighting-event-system/index.html)。照明をグループ化し、時間差・色・明るさ・回転を組み合わせる考え方を確認した。本作では照明の強弱を奥行きごとに遅らせ、左右のビームを緩やかに動かす。

Metallicaのリリーストレーラーも確認したが、見た範囲は主にシネマティック映像だったため、ゲーム中の配置の根拠には使っていない。音源の聴感評価やVR実機の操作評価は今回の観察に含まない。

## 本作への反映

### 新背景 Pulse Array

既存10背景に11番目として追加。プレイ開始時の抽選に入り、同じ起動中の連続選択を避ける。既存背景の番号を維持する。

暗いデッキ、8段の側面・天井フレーム、向きが変わる細い光を組み合わせる。通常は青紫寄り、登録済みの盛り上がり区間では琥珀色へ移り、外側のビームを開く。低い中央のノーツ通路は空ける。床の弱い光溜まりは床上の薄いメッシュ表現であり、実時間の鏡面反射ではない。

拍子や一定BPMを仮定せず、読み込んだ譜面の実時刻と曲固有オフセットから照明キューを作る。同時ノーツをまとめ、180ms未満の密集したキューを間引く。個人の判定調整は加えず、譜面は変更しない。キューのない区間も弱い連続した明暗で空間を維持する。譜面のキューは音楽照明の近似であり、曲ごとの専用ライトショーを作成したわけではない。

構造と照明の2メッシュ・2材質。動的頂点数に上限を持ち、照明ごとのGameObject・Collider・Lightは増やさない。曲時計から更新し、乱数で判定や破片の結果を変えない。

### セイバー

左右の色、細い白い芯、低輝度の周辺光を重ねる。端点16組まで・120msの刃全体の残光を使い、中点だけの太い軌跡は重ねない。停止・通信復帰・大きなワープ・無効化時は古い帯を消す。左右の色を材質と頂点へ二重に掛けない。

見た目の端点は従来の入力端点から生成する。判定範囲・速度・入力座標・スコアは変更しない。プロジェクター用の太さと暗い縁取りは維持し、残光は薄くする。

### 切断

短い75msの切断光と、主にスイング方向へ飛ぶ8本の細い火花。火花は240ms以内に消え、同時表示は12組まで。同じ場所の同時切りは統合する。成功した最終カットだけに反応し、ロング途中・失敗に成功演出を出さない。既存の二分割片を残し、全画面フラッシュやカメラ揺れは加えない。

## 確認方法

実Gameシーンに確認用ノーツを配置し、変更前後、通常・盛り上がり・プロジェクター表示、同時切り33ms・100ms・300msを撮影して比較する。次のノーツと判定結果を確認する。照明の可変拍間隔・密集時刻・巻き戻し、中央空間、頂点数、資源解放、刃の端点と無効化を自動テストで確認する。実機投影での最終的な見え方と、センサーを使った操作感は未確認。
