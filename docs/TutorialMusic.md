# チュートリアルの練習音源

120 BPM・4/4・2小節（8拍、4秒）のオリジナルループを、持ち方の説明から練習終了まで再生する。音源は `Assets/Resources/Audio/Tutorial_Loop120.wav`。柔らかい四分のキック、2・4拍の木質の打音、薄いハット、短い鍵盤の和音とベースで構成し、リード・派手なフィル・メトロノーム音は使わない。和声は Dmaj9 → Gmaj9。外部音源や既存曲のサンプルは使っていない。

48 kHz・ステレオ・16-bit PCM、192,000フレーム。UnityではPCMのまま事前ロードし、圧縮による先頭の余白を避ける。余韻をループ先頭へ折り返して継ぎ目をつなぐ。ピークは約−5.04 dBFS、RMSは約−21.45 dBFS。再生音量は `TutorialController.MusicVolume = 0.65`。切断効果音は従来の音量を使う。

音源・ノーツ・判定は同じ `SongPlayer` のDSP時計で動く。音源が周回しても譜面時計は巻き戻らない。各ステップは説明を読む0.9秒とノーツの接近時間を確保した上で、次の小節頭から始める。単発・矢印は1〜2秒間隔、通常の型は4秒周期、4方向の予備の型は8秒周期。ロングは到達時から0.5秒ごとに3回切る構成で、長さは1秒。判定調整は本編と同様にNoteSpawnerが一度だけ適用する。

終了・スキップでGameシーンを離れると再生を停止する。共有音源は破棄せず、チュートリアルへの再入場に使う。

再生成にはPython 3とnumpyを使い、リポジトリ直下で `python Tools/compose_tutorial_loop.py` を実行する。固定シードで同一のPCMを生成する。

関連テスト: `TutorialProgramTests`（全練習・繰り返し・ロングの拍合わせ）、`TutorialMusicTests`（正確な尺・PCM設定・各拍の振幅・継ぎ目）、`TutorialFlowPlayTests`（実Gameシーンで再生・周回・最初のノーツ・スキップ後の停止）。実機の音響出力遅延や会場での音量はこれらの自動テストの対象外。
