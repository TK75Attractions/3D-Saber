# 譜面編集で時刻と拍を保つ境界

2026-10-23、実際に破損する入力と対照条件を確認して以下を修正した。音源・採用譜面・ゲームの判定幅は変更しない。

- `Normalize` は有限の負の `time` / `beat` を保持する。例えば `offsetMs=500`、`time=-400` は音源の100ms地点の正当なノーツである。色など別の項目を編集して保存しても、500ms地点へ動かさない。非有限値の修復と、明示的に時刻・拍を編集する操作の0未満への制限は従来どおり。
- 難易度間の曲設定コピー・読み込みでは、前後で同じ2点以上のテンポ地図を持つ譜面の拍番号を保つ。代表BPMが120から150へ変わっても、その地図が同じなら格子は変わらない。地図なし・1点地図・地図の追加/削除/置換は既存の再計算条件を維持する。
- 外部JSONの `notes` 配列に明示された `null` を、保存時に0秒・中央の実ノーツへ変えない。元JSONの位置に基づいて除外し、正当な0秒ノーツ・負の値・入れ子の未知メタデータは保持する。位置が対応する単一のroot `notes` 配列だけを対象とし、重複キーや他の不正要素の意味は変更しない。

`SaberChartDocumentTests` は本編の `ChartLoader` を通した編集前後比較を含み、null混在の2件は修正前にノーツ数1→2・2→4で失敗した。`ChartEditorDifficultyTests` はコピー/読み込みの両方で同一2点地図を保持し、1点地図と追加/削除を対照として検証する。負時刻の3件も修正前に失敗し、変更後は成功した。

現行素材の全譜面に異常があったという修正ではない。負の座標への編集機能拡張、1点地図の操作間統一、地図の置換時の再計算、未知のノーツ項目の保持は別の検討事項として残す。
