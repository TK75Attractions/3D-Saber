# プレイ操作に応えるステージ演出

2026-09-19更新。音ゲー8作品を比較して実装した演出を、ユーザー指定の「ノーツ位置に対応する床4列」「Perfect限定」に調整した。

## ノーツと床の対応

| ノーツの横位置（左から） | 光を走らせる床 |
|---|---|
| 1・2列目 | 1列目（左外側） |
| 3・4列目 | 2列目（左内側） |
| 5・6列目 | 3列目（右内側） |
| 7・8列目 | 4列目（右外側） |

譜面エディターの横8列（X=-2.5～2.5）の最寄り列を2列ずつまとめる。coordScale適用後の実配置を使う。青でも右側のノーツなら右の床が光り、金も切った手で発光位置が変わらない。床の区切りはX=-6,-3,0,3,6で、光は対応する列の幅に収まる。

## 見え方

- Perfect：対応する床列へ山形の光と残光が走り、その側の照明が手前から奥へ連鎖する。切断位置には短い刃の光と火花が出る。
- Great / Good / Bad / Miss：床・側面・切断位置の追加の祝福光を新しく出さない。判定文字、切断片、ロングの残数やひびなど、操作結果を伝える基本表示は維持する。
- 譜面上の同時斬り：別の手で同時刻のノーツを短時間内に両方Perfectで切った時だけ強調。実際の2ノーツの床列へ光を出し、同じ半分の配置でも反対側を勝手に光らせない。片方がGreat以下ならPerfect側の通常光だけ。
- ロング：途中ではPerfectが未確定なので床の波や側面の蓄積光を出さない。完走し、方向降格後もPerfectとなった時だけ対応列の光と側面の二重の弧を解放する。時間切れや方向違いでのGreat以下には出さない。
- サビ：登録済みの強い演出区間の前に光が奥へ集まり、直前に追加照明が弱まる。区間の頭でビームが外へ開き、床に波が走る。サビの演出は成功・失敗や難易度に依存しない。

すべて既存11背景へ共通の表示層として重ねる。背景の色調に合わせた配色を持ち、プロジェクター設定では追加光の強さを下げる。カメラ、ノーツ移動、判定、譜面、音源は変更しない。

以前に出たPerfectの光は短い寿命で自然に消える。後続のGoodによって新しい光を出したり、寿命を延ばしたりしない。背景そのものの動きと基礎照明は維持する。

## 接続と境界

`StageReactiveEffects` は `GamePlayManager` が曲読込後に生成し、`NoteSpawner.OnNoteSpawned` からノーツを購読する。新しい `OnChartReset` で購読と一時表示を片付ける。独立したUpdateは追加せず、曲再生中の既存ループから曲時刻を渡す。

`ScoreManager` が方向降格まで含む最終判定を決めた後、該当ノーツの `OnJudged` を通知する。舞台と切断光はその判定を使い、前のノーツのLastTier、単なるOnCut、購読順の偶然でPerfectを推測しない。未判定の切断は発光しない。

`StagePerformanceTimeline.EvaluatePresentation` は従来の滑らかな区間強度を保ち、予兆・直前の抑制・入口の強調を別に評価する。区間の `anticipationSeconds`（既定2.4秒）と `impactSeconds`（既定0.8秒）を0にすれば、それぞれ省略できる。強度0.65未満の助走区間には入口の強調を適用しない。区間時刻は音源先頭基準で、個人の判定補正を含めない。

**アンダルシアは既存の区間指定が空のため、サビの時刻演出は出ない。** 斬撃・同時斬り・ロング反応は利用できる。音量や譜面密度からサビを推測して付ける処理は追加していない。将来、試聴して見せ場を指定できる。

波は最大10個で、同時に多く出ると明るさを抑える。表示用のメッシュと材質は各1個。床光は低く置き、立ち上がるビームと弧は中央通路外へ配置する。途中達成ロングの確定判定も、IsCutとIsMissedを確認して完走と区別する。曲停止では波も止まり、巻き戻しでは古い波を消す。

## 次に検討したい演出

今回の調整と同じ方針の追加案。以下は未実装。

1. **列ごとのPerfect連鎖**：同じ床列の対象ノーツを3回・5回連続Perfectにすると、その列の奥に短い光輪が開く。Great以下ではその列の連続数を静かにリセットし、発光しない。他列のカウントには影響させない。
2. **切った方向が床に残る**：Perfectの振り方向を、対応列の短い斜線や扇形に反映。左上・右下などの振り分けが光の違いで分かる。Great以下では追加の線を出さず、矢印ノーツも降格後の判定に従う。
3. **高さに応える側面の星粒**：Perfectノーツの高さに合わせ、対応側面の低・中・高に小さな星粒が一度現れる。床で左右、側面で上下の手応えを作る。Great以下では出さず、中央のノーツ付近には置かない。
4. **フレーズ全Perfectの紋章**：事前指定の短い音楽フレーズを全Perfectで完了したら、遠景の紋章が一段完成。Great以下を含むフレーズは追加発光を省略し、すでに完成した部分は急に消さない。難易度別の休符や必要打数を考慮する。
5. **最後のPerfectの余韻**：最後のノーツがPerfectなら、その列から光が奥へ広がって曲末まで薄れる。全Perfect達成時だけ追加の小さな光輪を重ねる。Great以下なら通常の曲終了へ進む。

次は「列ごとのPerfect連鎖」を推奨。今回の4列対応がそのまま手応えとして育ち、うまく斬れた時に舞台が豪華になることを理解しやすい。いずれも連打時の上限を持ち、ノーツの視認性を優先する。以前の「ラスサビの遠景変化」を採用する場合は、サビ突入時にだけ曲同期で発火させる。
