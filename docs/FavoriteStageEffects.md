# 共通の連打と背景固有の演出

2026-09-19 の演出候補から5案を採用。光学絞り（C07）は定期実装で追加。

| 演出 | 背景 | きっかけと動作 |
| --- | --- | --- |
| 連打の織り目 | 全背景 | 同じ床列で、譜面上の隣り合う通常ノーツが0.22秒以内にPerfectになると、床に短い帯と縫い目が残る。各節は0.5秒で消える。 |
| 葉の着水 | 月夜の庭園 | Perfectで側面の池へ葉が下り、接点から二重の波紋が広がる。1.2秒で消える。 |
| 圧力計と弁 | 琥珀の工業背景 | Perfectで側面の圧力計の針が振れ、少し遅れて弁が戻る。0.65秒で静止姿勢へ戻る。 |
| 光学絞り | 青い研究所 / AzurePrism | Perfectで6枚の金属羽根が0.16秒で締まり、0.10秒保持し、0.45秒で開く。1周期0.71秒。 |

## 共通と固有の組み合わせ

床4列の反応は共通。8列のノーツ配置を、実際の横位置から2列ずつ床へ対応させる。ノーツの色・担当の手では決めない。

庭園・工業・研究所では、通常の側面の成功光を固有演出へ置き換える。床の山形の光、同時Perfect、ロングの完走、連打の織り目は残す。左右それぞれの2列は池や装置の手前・奥を分ける。

庭園の同じ場所への連打は、進行中の葉と波紋へまとめる。落下を毎回やり直さず、最初の着水から消えるまでを保つ。床の共通反応は毎回のPerfectで出る。

研究所も、動いている同じ絞りの周期を再開始・延長しない。後から予約再生もしない。連打中の各打は共通床が返し、装置は一度開き直す。外周と取付座は固定し、羽根だけを動かす。追加の閃光・反射・屈折・音は使わない。LOW設定では閉じ量と細部の光を30%へ抑えるが、周期と成功条件は同じ。これは動きの抑制であり、描画負荷が70%減るという意味ではない。既存の保存設定を尊重し、削除済みの選曲画面の設定ボタンは戻さない。

成功演出は方向による降格も終えた最終Perfectだけを受け取る。Great以下、Miss、ロング途中には追加しない。織り目は同時ノーツ群・ロング・同列の失敗・未確定ノーツを飛び越えてつながらない。他列の判定は対象列の連打を切らない。

惑星の食は成功演出とは独立する。`stage.json` の有効な区間のうち、強度0.65以上・長さ8秒以上で最大強度のものを使い、同じ強度なら後の開始を選ぶ。その区間の中央、最大16秒を滑らかな0→1→0で評価する。明示区間のない曲では出さず、譜面密度から推測しない。難易度による違いもない。

## 時計と描画

`GamePlayManager` の曲時計から進め、独自のUpdateは追加しない。同じ曲時刻で停止、巻戻し・譜面の再読込・無効化で成功演出を消す。ノーツの判定、得点、カメラ、譜面、音源は変えない。

- 織り目は各列8節、計32節。各節の寿命は独立し、後の成功で延長しない。既存の共通メッシュ内で描く。
- 庭園・工業・研究所は4状態、結合メッシュ2枚・材質2個を生成時に確保。Perfectごとの物体生成を行わない。研究所は金属面960頂点と細部672頂点。稼働時・設定変更時だけ再描画する。
- 食は既存の惑星材質を使用。右上の大惑星の局所範囲だけを暗くし、小惑星・環・他背景を変えない。
- ライト、カメラ、物理演算、ParticleSystem、画面全体の後処理は追加しない。
- 投影モードでは成功光の明るさを抑える。演出は床か通路の外側に置く。

## 確認箇所

`StageReactiveEffectsTests` は実際のノーツ確定判定から連打・失敗・同時群・ロング・巻戻し・再開を検証する。`StageThemeResponseTests` は背景固有の位置、寿命、固定上限、資源解放を検証する。`EclipseTests` は区間選択、時間曲線、材質の対象範囲と解除を検証する。

揺籠で報告された既存のUnityネイティブクラッシュについて、今回の追加は原因の修正を意味しない。再現確認の条件と結果は作業記録へ別に残す。

## 光学絞りの調査と採用理由

操作、音楽・照明、背景・描画の3役が独立に調べ、相互レビューした。共通床の即時反応を維持し、側面は素材の動きを見せるという役割分担を採用した。0.71秒は本作で選んだ固定周期であり、参考作品の実測値でもBPM同期でもない。

- [Hi-Fi RUSHの開発者による制作回顧](https://news.xbox.com/en-us/2023/10/04/hi-fi-rush-exclusive-oral-history/)の応答性とリズム感を両立する考えを、床の応答を保つ設計の参考にした。
- [Thumper開発者の記事](https://blog.playstation.com/archive/2015/06/08/thumper-brings-rhythm-violence-to-ps4-in-2016/)の、限られた操作と一貫した視覚・身体的反応を重視する考えを参考に、装置の開閉へ表現を絞った。
- 上記は記事本文を確認した範囲。映像の再生・実機体験を行ったと扱わず、本作への適用は独自の判断として区別した。
