# El Dorado 短縮版への差し替え

2026-10-07、提供された「El Doradoーshort ver.(10_6).mp3」へ差し替え。配布ファイルは提供MP3そのもの（再エンコードなし）。旧版は223.248秒、新版は144.065306秒。BPM100と元の配置を保ち、曲IDと音源の `.meta` は維持する。

## 時刻の対応

波形を全曲で照合すると、冒頭は同じ位置、中盤は旧版から67.2秒、終盤は76.8秒を引いた位置で対応する。48kHzへ揃えた8区間の照合では共通して約3.021msだけ新版の音が遅い。ノーツと演出には3msを加え、誤差は約0.021ms。ミックス・余韻に差があるため、波形全体が同一という意味ではない。

| 旧音源の区間 | 新時刻への変換 |
| --- | --- |
| 冒頭〜約11.4秒 | +0.003秒 |
| 約11.4〜78.6秒 | 削除（112拍） |
| 約78.6〜186.6秒 | −67.197秒 |
| 約186.6〜196.2秒 | 削除（16拍） |
| 約196.2秒以降 | −76.797秒 |

接続点はBPM100の拍格子上で扱う。元の譜面は拍の約4〜5ms手前に置かれているため、区間所属の判定には10msの許容を設けた。196.195秒・196.196秒のノーツを誤って捨てず、新版119.398秒・119.399秒へ移す。全体のテンポを伸縮したり、ノーツを量子化したりはしない。
