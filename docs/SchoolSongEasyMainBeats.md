# 校歌Easyの表拍改訂

2026-09-18。ユーザーの「Easyは表拍中心、裏拍はできるだけ避ける」方針に合わせ、Easyの6打だけ採用する音を選び直した。133ノーツ、表示Lv.2、色・位置・方向、フリック8個、ロング2個、左右交互の配置を保持する。Normal・Hard・互換chart.jsonは変更しない。

初稿は主旋律の長い音を優先したため、PDF第5・9・28・32・54・58小節で、小節頭から2.5拍後（小節内local 2.5）の音を拾っていた。各小節の直前の表拍local 2.0にも同じ主旋律声部の発音がある。Easyではこの表拍の音を選び、歌の裏拍は上位難易度に残す。

制作時の楽譜抽出データで、前4か所はstaff 2、後2か所はstaff 5の長さ0.5拍の発音を確認した。全6打の時刻は既存Normal・Hardの同beatで一致する値を使用した。全体BPM92とoffset1296msを維持し、後半の加速を固定BPMで再計算していない。個人の判定補正も焼き込んでいない。

各変更箇所の前後の打点間隔は約1.304秒・0.981秒・0.945秒の等間隔になり、変更直前の同じ手の打点からは最短約1.88秒ある。6打の削除案も比較したが、既存の左右交互とフレーズの2打を保持する表拍への差替を採用した。譜面全体の最短間隔や同時切り数、ロング中の占有は変わらない。

## 参考と採用理由

- [BSMG Downmapping](https://bsmg.wiki/mapping/downmapping.html)：低難度は曲の特徴を保ちながら複雑さを減らし、読みと回復の余裕を設計する。今回はノーツを一律に間引かず、反復するフレーズの左右の動きを保った。
- [osu!mania制作基準](https://osu.ppy.sh/wiki/en/Ranking_criteria/osu!mania)：音への対応と難度に合うリズム密度を両立する。表拍の実在音と既存の変速時刻を確認してから変更した。
- [osu!taiko制作基準](https://osu.ppy.sh/wiki/en/Ranking_criteria/osu!taiko)：どの音楽要素を拾うかを明確にし、予測できる間隔と休みを設ける。今回は同じ主旋律声部を選び続け、単発の裏拍による間隔の揺れを減らした。

これらは本作への設計上の応用であり、他ゲームの認定基準を満たしたという意味ではない。本作は青が左・赤が右、金はどちらでも切れ、ロングは保持ではなく複数回切る。VR・鍵盤・打撃の操作規則をそのまま移植しない。

リズム役、身体動作役、初見・難度役の3役で独立確認後、削除案と差替案を相互検討した。今回の根拠は既存のPDF照合済み制作記録・抽出イベントと譜面比較であり、新たな聴感確認・実機プレイは未実施。制作元の旧V2出力を履歴として保持し、将来旧ジェネレーターで再生成する際はこの6打の個別採音を再適用する。
