# 判定調整画面

来場者は画面に入るとそのまま練習できます。基準音とノーツは連続し、中央には「音に合わせて切ろう」を表示します。

- カット領域の下に横棒と点を表示。緑の帯は本番と同じPERFECT幅（早め42.5ms、遅め85ms）。帯外は黄、帯内は緑。青と赤を早い・遅いの意味で使いません。
- 単発の早い・遅いは文字で出しません。6回以上のカットから、左右各2回以上、左右差35ms以内、ばらつき25ms以内、有効入力80%以上、直近の見逃し25%以下を満たす場合に傾向を出します。70%以上がPERFECT帯外の同じ側なら該当ボタンを光らせます。
- 下段は「戻る」「← ノーツを早く」「決定」「ノーツを遅く →」。早くは−10ms、遅くは＋10ms。保存前の下書きに反映し、音源は再起動しません。
- 安定したずれが60ms以上あると「おすすめに合わせる」が出ます。マウス入力を含む場合、判定可能範囲の端へ偏る場合、設定上限を超える場合には出しません。押すと中央値の分だけ寄せます。結果画面や24ノーツの再測定は不要です。
- 設定を変えた直後は以前の点が薄く移動し、新しい位置を予告します（最大3秒）。新しいカットで実測点に入れ替わります。以前の測定履歴は消し、再び6回集まるまでは案内を出しません。
- 速さは別の3択。「ゆっくり」「ふつう」「はやい」で、到達まで2秒・1秒・0.5秒。秒数は来場者画面に表示しません。
- 「決定」で判定値と速度を保存して選曲へ。「戻る」は変更があれば破棄を確認し、「続ける」で練習を再開します。保存と戻るは1.5秒、調整は1秒の滞留。どれも再実行には照準を外す必要があります。
- 時間は選曲から引き継ぎ、残り15秒から「あと15秒で選曲にもどります」と大きく表示します。0秒では変更を保存せず選曲に戻ります。
- フォーカスや音声機器の変更による中断時だけ「再開」を表示します。

## スタッフ画面

F2で開きます。開くと練習を止め、「練習へ」またはF2/Escで再開します。プロフィール、音量、接続状態、現在値、±1ms、自動測定、元に戻す、操作キー一覧を集約します。元に戻すは2秒の滞留です。音の出力先自体はOSで切り替えます。

スタッフの自動測定は従来の品質条件と24ノーツの検証を維持。保存前に確認できます。通常プレイの判定・採点・セーバー入力は変更していません。

## 検証

CalibrationLiveTestsでPERFECT境界・6回の傾向・左右差・ばらつき・見逃しからの回復を検証。CalibrationFlowPlayTestsで自動開始、連続音源、推薦と上限、下書き、照準滞留、ダイアログ、中断再開を検証。CalibrationCountdownPlayTestsで選曲の復元・保存・破棄・15秒警告・時間切れを検証します。

CalibrationScreenCapture.Renderは実Gameシーンの1080p/720pとLOWを撮影し、表示中の文字切れを確認します。履歴・提案は表示検査用の合成入力で、実機測定ではありません。
