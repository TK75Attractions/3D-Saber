# 判定調整画面

2026-10-03。画面は `CalibrationOverlay`、再生・測定は `CalibrationController`、設定と集計は `CalibrationSession`。

## 操作

- 「試し切りを始める」から一定間隔のノーツを切る。青は左手、赤は右手。基準音だけが鳴る。
- 直前の入力を日本語とFAST/LATEで表示し、直近最大24回をメーターで示す。白線は最新の入力、中央の帯は±8msの目安。本番のPERFECT幅ではない。
- 8回未満は傾向の判断を促さない。中央値・ばらつき・左右差を確認し、安定して同じ方向にずれるときにだけ調整方向を案内する。見逃しは0msのカットとして扱わない。
- FASTが続くなら負側、LATEが続くなら正側。既存の補正式 `noteTime + extraOffset + offsetMs / 1000` に従う。曲や判定窓のデータを編集しない。
- 現在値と保存済み値を併記。「保存値に戻す」は選択中の出力先の判定値と、入場時のノーツ速度に戻す。試し切り中でも音を止めずに反映する。
- 判定・速度・プロフィールを変えたら、以前の入力分布を消す。違う設定の結果を混ぜない。
- Spaceで開始/停止、左右キーで1ms、Shift+左右キーで10ms、1/2/3で速度、Escで停止/戻る。クリックと、選曲と同じ照準をボタンに1秒合わせる操作も使える。
- 照準は棒1の追跡位置またはマウスで動く。リングでホールドの進捗を表示し、実行後は一度外すまで再実行しない。試し切り中も照準を表示するが、ホールド操作は下端の操作帯だけに限定する。
- 追跡が0.2秒以上途切れたらホールドを取り消す。マウスへ戻すにはマウスを動かす。フォーカス喪失・画面遷移・長いフレームでも溜め直す。ゲーム内のセーバーと切断判定の座標は変更しない。

## 自動測定

両手の入力が直近にあり、残り時間が25秒以上ある場合に使える。準備4ノーツの後、24ノーツを測定する。進捗と有効な入力数を表示し、下端の一時停止は測定中も使える。

既存の中央値/MAD、入力数、左右差、前半後半の差、カメラ接続、処理落ち、入力種別、調整範囲の検査を経た結果だけを提案する。提案で保存値を上書きせず、有限の試し切りへ進む。試し切り後の保存は利用者が明示する。ライブ表示の履歴から自動提案は生成しない。

測定終了は最後のノーツの補正後の到達時刻を基準にする。画面のフォーカスや音声設定が変わったら停止し、古い履歴を消して再確認を案内する。

## 保存と時間

PCスピーカーと有線イヤホンのプロフィール、速度3段（2.0 / 1.0 / 0.5秒）、保存・破棄、選曲との残り時間引き継ぎは既存仕様を維持する。音声デバイス自体はWindowsで切り替える。

0秒では未保存の変更を破棄して選曲へ戻る。残り時間と「0秒で保存せず戻る」をダイアログより前面に表示する。

## 検証

`CalibrationLiveTests` は履歴の上限、見逃し・非有限値の扱い、方向案内と品質条件を確認。`CalibrationFlowPlayTests` は本物のGameシーンで測定UI・提案の試用・ライブ復帰・上限ボタン・残り時間による制限を確認する。既存のカウントダウン・保存破棄・画面遷移・曲時計のテストも併用する。

`CalibrationScreenCapture.Render` はGameシーンの1080p/720p画像、LOW設定、設定画面、破棄確認、上限値、提案あり/入力不足の結果を撮影し、表示中のTMP文字切れを検出する。カット・履歴・提案のサンプルは表示検証用であり、カメラ/BLEや人間の動作、実スピーカー・投影機の遅延の測定結果ではない。
