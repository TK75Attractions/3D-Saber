## 結論

- **この 2 本では、どの判断もできない。** 保存された画像(各 12 枚、実質 11 frame)は、録画の**開始直後と停止直前**ばかりで、撮影手順の中身(静止・端から・振り)がほぼ残っていない。
  - 005325: 198–205 は開始 2 秒(カメラの前に人が近い。赤 saber は映っていない)、3302–3306 は終了間際(消灯した saber を持っている)。

- **CASE A: 本物の saber では 0 件。** CASE A ヒント 4 件はすべて背景どうし(またはカメラ外の saber の光が当たった背景)。修正 A の gate は未達のまま。

## 5. 露出の比較(自動 vs 上限 1/100)

| 指標 | 自動(005325) | 1/100(005855) | 注意 |
|---|---|---|---|
| 実際の露光(保存 frame) | 1/50 | 1/100〜1/106 | 自動は開始時 1/30、保存 frame はすべて 1/50(夜の室内) |
| ISO(保存 frame) | 320〜800 | 640〜2000 | 1/100 では ISO が約 2 倍になり、明るさを補う |
| 赤 検出率(全 frame、予測込み / 予測なし) | 98.4% / 97.8% | 95.5% / 93.3% | ラベルがないので、背景の誤検出も含む |
| 青 検出率(同上) | 97.5% / 96.7% | 90.4% / 89.0% | 同上 |
| 保存 context 267 frame の eligibleZero 赤 / 青 | 13 / 61 | 40 / 98 | 区間の中身が違う(後者は消灯と停止操作を多く含む) |

| 背景の赤 winner(保存 frame) | 10/11 frame | 7/9 frame(saber なしの frame) | 1/100 でも背景の誤検出は残る |
| 速い振りのブレ・細長い blob | 保存なし | 保存なし | **測定不能** |
| CASE B(ブレによる取りこぼし) | 0 | 0 | どちらも速い振りの frame が保存されていない |

- 「全体を暗くすると背景の誤検出が減る」(10-03 の gain 0.92 の実験)は、露光時間の上限では起きない。ISO が自動なので、画面の明るさは保たれる。
- 1/100 で ISO が 1600〜2000 まで上がった frame は、指がレンズを覆った暗い場面だけ。通常の場面は 640。
- **交絡**: 2 本は撮った瞬間が違い、ラベルもない。検出率の差は、露出の効果とは言えない。

### 推奨

- **既定は自動のまま。** 1/100 を既定にする根拠(ブレの減少、CASE B の減少)は、今回のデータでは示せていない。
  ただし、悪い兆候(saber が暗くなる、ISO ノイズで不安定になる)も見えていない。既定の変更はユーザーの判断。
- 速い振りのブレを比べるには、振っている最中の frame が保存されることが前提になる(次の 1)。
