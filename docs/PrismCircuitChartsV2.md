# PRISM CIRCUIT 譜面 v3 — 高さと配置の修正

2026-10-03。「同時の高さをそろえる」「似た配置を減らす」「低い上向き・高い下向きを避ける」という指摘を3難易度へ反映。

| 低い上向き／高い下向き（個） | 0 → 0 | 28 → 0 | 115 → 0 |

配置の比較は5～68小節のうち2ノーツ以上ある小節を対象とし、座標を0.2単位に丸めています。同じ並びの細かなずらしだけを違いと数えないためです。指標は構造上の反復を測るもので、体感の面白さを保証するものではありません。

## 配置の変更

同時打ちは左右で同一のY座標。上下2段を交互に固定していた配置をやめ、4小節のまとまりごとに次の6種類の動きを使い分けます。

- 歩くような小さい左右の移動：導入・Aメロ・間奏。
- 階段状の上昇と下降：Aメロの展開、ビルド、最終サビの入り。
- 横幅の往復：サビ前半の応答と再加速。
- 広がって戻る配置：第1サビの入りと最終フレーズ。
- 斜めに流れて折り返す配置：サビ後半と最終サビ中盤。
- 高低を入れ替える波形の配置：第1サビ末尾と再ビルド。

Normalは一部の小節で表拍と裏拍を入れ替え、Hardは第1サビ後半の8小節を別の応答リズムに変更。全打点は元の演奏イベントに対応させています。

上向き（斜めを含む）は高い位置、下向きは低い位置に配置。横移動には左右の矢印も使用します。現在の切断位置へ向かう動きと矢印の向きを照合し、連続する方向指定で同方向への振り直しを要求しないよう確認しています。金の直後は各手とも方向自由です。

## 維持した条件と検証

- Easy／Normal／Hardの表示はLv.3／5／8。音源、148 BPM、同時打ち数、金の数、ロング2か所は維持。
- 同じ手の最短回復は810.810／405.405／405.405ms。Hardの7回金ロール内部は202.703msで左右交互が目安。
- 最大移動速度は1.766／4.193／4.068座標単位/秒。ノーツ位置の変化に伴いv2から少し増えますが、検査上限4.5以内。物理空間のm/sではありません。
- 静かな間奏の密度は引き続きサビの60%未満。同時はサビに集中させ、金・方向・通常の役割を分けています。
- 検証結果は `verification.json`、定量値は `validation.json`、Unityの結果は `unity-tests.xml` に記録。

人間がセイバー・カメラ・IMUで振った際の快適さは未確認です。
