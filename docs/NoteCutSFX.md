# ノーツ切断音

外部素材・既存ゲームの音を使わず合成した、3D-Saber用のオリジナル効果音です。

| ファイル | 用途 | 長さ |
| --- | --- | --- |
| `Saber_NoteCut.wav` | 通常の切断音。短い斬撃に硬いヒット感を重ねた音 | 0.22秒 |
| `Saber_NoteCut_Rapid.wav` | 短い通常音の別案。既定の接続では未使用 | 0.13秒 |
| `Saber_FlickCut.wav` | フリック。高域へ跳ね上がる空気音と鋭い上昇音 | 0.19秒 |
| `Saber_LongTick.wav` | Long途中。短い「コツ・ジッ」という刻む音 | 0.12秒 |
| `Saber_LongFinish.wav` | Long完了。刻む音から明るく解放する音 | 0.28秒 |
| `Saber_GoldCut.wav` | 金ノーツ。1打で「シャン」と響く金属音 | 0.58秒 |

すべて 48 kHz / 16-bit PCM / モノラルです。開始に待ち時間を設けず、音の終端は滑らかに減衰させています。

## Unityで使う

3D-Saberへの組み込み済みです。通常のゲーム開始操作で、自動的にノーツの種類に合った音が鳴ります。追加の音源割り当ては不要です。

音を差し替える場合は、下記コンポーネントのAudioClip欄に別の音源を設定します。音量は各コンポーネントのVolumeで調整できます（ゲーム開始時に既存の音量上限が適用されます）。

2026-09-22の追加調整で、切断音の音量係数を従来の1.25倍にしました。通常・フリック・Long完了は `0.8 → 1.0`、金ノーツは `0.75 → 0.9375`、Long途中は `0.55 → 0.6875`。コンポーネント既定値・開始時の上限・Gameシーンの保存値を揃えています。Missは `1.0 × 0.44 = 0.44` とし、従来の `0.8 × 0.55` と同じ大きさを維持します。曲の音量は変更していません。

ゲーム内の同梱先は `Assets/Resources/Audio/SFX/` です。通常・フリック・Long完了音は `JudgmentSfx`、Longの途中カットは `LongNoteCutSfx`、金ノーツは `GoldNoteSfx` が読み込みます。通常音は判定別のClip欄、フリックはFlick Clip、Long完了はLong Finish Clip、途中と金はそれぞれのCut Clip欄を使います。これらに個別の音源が設定されている場合は、その設定を優先します。

金ノーツには通常カット音を重ねません。Longは切り切ったときだけ完了音が鳴り、時間切れでは鳴りません。Missの通知音は既存の音を使用します。`Saber_NoteCut_Rapid.wav` は短い通常音の別案として同梱し、既定のゲーム接続では使いません。

2026-09-23: 切断系6音源(通常・Rapid・フリック・Long途中・Long完了・金)の波形そのものを +5 dB しました(ffmpeg volume=5dB、48 kHz / 24-bit / モノラルと長さは不変、ピークは通常 -4.1 dBFS・フリック -3.9 dBFS)。コンポーネントの音量係数(通常1.0 / 金0.9375 / Long途中0.6875)は変更していません。Miss音は据え置きなので相対的に約5 dB控えめになります。左右同時カットで同じ音が重なると +6 dB になるため、これ以上は音源側ではなく曲側の音量で調整してください。
