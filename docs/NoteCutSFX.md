# ノーツ切断音

外部素材・既存ゲームの音を使わず合成した、3D-Saber用のオリジナル効果音です。

| ファイル | 用途 | 長さ |
| --- | --- | --- |
| `Saber_NoteCut.wav` | 通常の切断音。短い斬撃に硬いヒット感を重ねた音 | 0.22秒 |
| `Saber_NoteCut_Rapid.wav` | 連打・Longの途中カット用。短く軽め | 0.13秒 |

どちらも 48 kHz / 16-bit PCM / モノラルです。開始に待ち時間を設けず、音の終端は滑らかに減衰させています。

## Unityで使う

1. WAVファイルをUnityのProject欄（例: `Assets/Audio/SFX`）へドラッグします。
2. 切断音を鳴らすコンポーネントのAudioClip欄へ割り当てます。名前は実際のプロジェクトの実装によって異なります。
3. 最初は音量を0.3〜0.5程度で試し、曲に合わせて調整してください。

ゲーム内の同梱先は `Assets/Resources/Audio/SFX/` です。通常カットは `JudgmentSfx`、Longの途中カットは `LongNoteCutSfx` が読み込みます。Inspectorに個別のクリップが設定されている場合は、その設定を優先します。

Missの通知音と金ノーツ専用の金属音は既存の音を使用します。
