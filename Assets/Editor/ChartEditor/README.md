# 3D Saber 譜面エディター 利用ガイド

スマホで曲を聴きながらタップ・長押しで作る場合は、[Saber Tap Studio](../../../Tools/MobileChartStudio/README.md)を使えます。端末内で音源と下書きを保存し、このUnityエディターと同じ譜面JSONを書き出します。

このツールは、3D Saber 専用の新しい **Unity EditorWindow 版譜面エディター**です。
`Assets/Note-Recorder/` にある旧譜面エディターとは別物で、旧シーンを開いたり Play モードに入ったりする必要はありません。

## 起動方法

1. Unity Hub から、このリポジトリの `Assets/`、`Packages/`、`ProjectSettings/` があるフォルダーを開きます。
2. Unity のコンパイルが完了するまで待ちます。
3. Unity 上部メニューの **`3D Saber/譜面エディター`** を選びます。
4. 開いたウィンドウは、必要に応じて Unity の他のウィンドウと同じようにドッキングできます。

メニューが表示されない場合は、Unity Console にコンパイルエラーが出ていないか確認してください。

## 基本的な作業の流れ

1. ヘッダーの「開く・作る」で曲フォルダー名と難易度を選び、「読込」で既存の譜面を開くか、「新規」で空の譜面を作ります。
2. BPM、オフセット、拍子を設定します（「新規」では同じ曲の他の難易度から引き継ぎます）。
3. プロジェクトへ取り込んだ音源を選び、波形と再生位置を確認します。
4. Snap の細かさ、ノーツの色、種類を選びます。
5. 縦タイムラインでタイミングを決め、XY パッドで出現位置を決めます。
6. 必要に応じて方向、Long のカット回数などを調整します。
7. 保存後、本編の曲選択またはテストプレイで確認します。

作業を終える前や別の譜面を開く前には、未保存表示を確認して保存してください。

別の譜面を開く際に「保存しない」を選んでも、ファイル破損や読み取りロックなどで読み込みに失敗した場合は、元の編集内容・未保存表示・Undo/Redo履歴が残ります。曲一覧からの切り替えでは、保存先も読み込み成功後に切り替わります。不正な曲フォルダー名はエラーを表示し、空の譜面への置き換えは行いません。

## 保存の決まり（触っていない値を変えない）

- **保存先は「編集中」に表示している曲・難易度です。** ヘッダーの「開く・作る」で別の曲や難易度を選んでも、読み込むまでは保存先は変わりません。選択が編集中と違うときは上部に「未読込」と出ます。「ここへ複製」は今の内容を選択中の曲・難易度の新しい譜面として開き（曲の設定も引き継ぎ、保存するまでファイルは書きません）、「選択を戻す」で選択を編集中に戻します。未保存の確認で「保存」を選んだ場合も、編集中のファイルへ保存します。
- **変更がなければ保存しません。** 開いて「保存」を押したり、「本編でテスト（保存なし）」で試したりしただけでは、ファイルは書き換わりません（変更があるときはボタンが「保存して本編でテスト」になります）。
- **保存で値を書き換えません。** 制作メモ（`_comment`）など本編が使わない項目は、ファイルの先頭にそのまま残します。触っていないノーツの拍の値（`beat`）は保ち、置いた・動かしたノーツだけ今の格子に合わせます。拍の値が1つの BPM に乗っていない譜面（テンポが変わる曲）では、BPM を変えても拍の値を計算し直しません。
- **グリッド原点の推定値は表示だけに使います。** 原点の欄がない譜面（ElDorado など）は、ノーツの拍と時刻から原点を推定して格子を表示しますが、ファイルの値（本編の小節線とカウントイン）はそのままです。設定欄の下に「ファイルの原点は 0ms のまま」と出ます。ファイルにも書くときだけ「表示中の原点をファイルにも書く」を押します。原点の欄を直接変えた場合もファイルに書きます。
- **新規で既存の譜面を黙って置き換えません。** 「新規」や「ここへ複製」の保存先に譜面があれば、保存前に確認します（置き換え前のファイルはバックアップされます）。
- **数値の欄は `Enter` か欄を離れたときに確定します。** 1文字ごとに Undo の履歴を増やしません。
- **Undo の履歴は再コンパイルや Play の開始をまたいで残ります。** 未保存の印も、開き直したときに内容から計算し直します。
- **下書き:** 未保存の変更がある間は、5分ごとに `Library/3DSaberChartDrafts/` へ下書きを保存します（新しいものから15個）。Unity が終了したあとに同じ譜面を開くと、右の上部に「保存していない下書きがあります」と出ます。「下書きを開く」で戻し（保存するまでファイルは変わりません。Undo で開く前に戻せます）、「下書きを捨てる」で消します。保存するとその譜面の下書きは消えます。

## 画面と操作

### 縦タイムライン

縦タイムラインは、曲の時間、拍、小節を縦方向に並べて表示します。添付イメージのように、前後のノーツを見ながら配置とタイミングを編集するための中心画面です。

- 太い線は小節、細い線は拍や Snap の区切りです。
- 波形は音の位置を探すための目安です。
- クリックした位置は、現在位置またはノーツ配置時刻になります。**再生中のクリックはシークだけ**で、ノーツを置いたり消したりしません。
- ノーツは**実際の横位置**に描きます（8列に丸めないので、録音キーの G と J のように列の間にあるノーツも別の位置に見えます）。重なったノーツは、同じ場所をもう一度クリックすると下のノーツを順に選べます。
- ノーツを選択すると、種類、色、方向、位置などを編集できます。
- ノーツをクリックしただけでは動きません。4px 以上ドラッグすると、元の時刻から Snap の整数倍、元の横位置から列の間隔の整数倍だけ動かします（録音した細かな時刻や位置の端数は保ちます）。`Shift` を押しながらドラッグすると、格子と列の中心へ吸い付けます。
- 右クリックすると、その位置のノーツを削除できます。
- マウスホイールで前後へシークします。**1ノッチ＝1拍**で、Snap の細かさによりません（`Shift`＋ホイールは Snap 1つ分）。
- `Ctrl` または `Cmd` を押しながらホイールを回すと表示倍率を変更します。
- タイムラインの左上に、いまの Snap を常に表示します。
- 右端の細い帯は**曲全体の見取り図**です。ノーツの多さ、サビの区間（`stage.json`）、目印、いま見えている範囲（白枠）を表示し、クリックやドラッグでその位置へ移動できます。

### 小節・時刻へ移動、目印

右の「再生 / シーク」で、小節番号か時刻（`1:23.5` または `83.5` 秒。音源の先頭からの時刻）を入れて「移動」を押すと、その位置へ移ります。

「目印」に名前を入れて「現在位置に追加」を押すと、タイムラインにオレンジの線と名前が出ます。一覧のボタンで移動、`×` で削除します。目印は譜面ファイルの `editorMarkers` に保存し（本編は読みません）、「新規」「ここへ複製」で他の難易度へも引き継ぎます。

### 範囲の編集

範囲は時刻で決め、「始め以上・終わり未満の時刻に始まるノーツ」が対象です（スマホ版と同じ決まり）。

- `[` で今の位置を範囲の始め、`]` で終わりにします。左の目盛り（小節番号の列）を `Shift`＋ドラッグしても選べます。「ここから最後」は今の位置より後ろを全部、「全体」は譜面全体を選びます。`Esc` で解除します。
- 範囲を選ぶと、右に「範囲」の操作が出ます。左右反転（横位置・赤青・矢印の左右。`Ctrl+M`）、色だけ入れ替え（`Ctrl+Shift+M`）、削除（`Delete`）、コピー（`Ctrl+C`）と今の位置への貼り付け（`Ctrl+V`）、後ろへ複製（範囲の直後に同じ並びを置き、範囲をそこへ移す。`Ctrl+D` を続けて押すと繰り返せます）、時間の移動（±1 Snap は `Ctrl+↑/↓`、ms 単位も指定可）、色・種類の一括変更ができます。方向キーは範囲のノーツにまとめて付きます。
- 時間を動かすと範囲も一緒に動くので、続けて動かせます。「ここから最後」＋時間の移動で、今の位置より後ろをまとめてずらせます。
- 貼り付け・複製の先に、同じ時刻・位置・色のノーツがあれば元のノーツを残し、重ねて足しません。どの操作も1回の Undo で戻せます。

### 方向をキーで付ける

`Q W E / A S D / Z X C`（`S`＝なし）かテンキーの `1〜9`（`5`＝なし）で、選んだノーツ（範囲を選んでいれば範囲のノーツ）に方向を付けます。TAP は方向ノーツになり、LONG は LONG のまま方向だけ変わります。左の「方向を付けたら次のノーツへ」がオンなら、付けたあと次のノーツを選びます。選んでいないときは、次に置くノーツの方向（左のパレット）を変えます。

- **再生中に方向キーを押すと、その時刻にいちばん近いノーツ（前後200ms以内）に方向が付きます。** 録音と同じ音声の時計と入力補正を使います。同時打ちは左のノーツから順に付きます。止めるまでの方向付けは1回の Undo で戻せます。
- 録音・ステップの画面では D F G J K が入力キーなので、文字の方向キーは使わず、テンキーだけが効きます。ステップでは今の拍のノーツに、録音中は次に打つノーツに方向を付けます。

### 曲の途中で拍子を変える

右側の **「拍子 / 途中の拍子変更」** で曲頭の分子・分母を指定します。変更したい位置へシークして **「現在位置に追加」** を押し、その行の分子・分母を変更してください。開始拍は四分音符単位で直接修正でき、横に小節番号と秒数も表示します。不要な変更点は `×` で削除できます。

- 例：開始拍 `8` を `7/8` にすると、小節頭は `0 → 4 → 8 → 11.5 → 15` と進みます。
- 変更点は新しい小節の先頭です。元の小節の途中なら、その小節をそこで区切ります。
- 太い小節線、分母に応じた拍の線、小節番号、Snap が変更後の拍子に追従します。
- `Shift+← / →` は前後の小節頭へ移動します。
- 拍子の変更・削除は元に戻す／やり直しに対応し、譜面の保存・読込、本編テストにも引き継がれます。曲ごとの設定なので別の曲へ読み替えても混ざりません。
- 拍子の編集で既存ノーツの時刻は変わりません。拍子とBPMは別の設定です。

譜面JSONの `timeSignatures` は `{ "beat": 8, "numerator": 7, "denominator": 8 }` の配列です。未指定の旧譜面は従来の4拍として扱います。`beatZeroMs` はグリッド原点で、全体OFFSETとは別に保存されます。本編の小節線にもノーツと同じOFFSET・プレイヤーのタイミング調整を一度だけ加算します。

### XY パッド

3D Saber のノーツには、タイミングだけでなく判定面上の X・Y 座標があります。XY パッドは、現在選択している時刻のノーツを左右・上下のどこへ出すか決める画面です。

- 横方向が X、縦方向が Y です。
- グリッドへ配置すると、本編で使用する座標へ変換されます。
- 同じタイミングでも異なる位置へ複数のノーツを置けます。
- タイムラインは主に時間、XY パッドは主に空間配置を確認するために使います。

### 色

| 色 | 本編での意味 |
|---|---|
| 赤 | 右手のセーバーで切るノーツ |
| 青 | 左手のセーバーで切るノーツ |
| 金 | どちらのセーバーでも切れる特別ノーツ |

既存譜面との互換用に色指定なしを扱う場合も、どちらのセーバーでも切れるノーツとして扱われます。

### ノーツの種類

| 種類 | 内容 |
|---|---|
| Tap | タイミングに合わせて1回切る通常ノーツ |
| Direction | 指定方向へ切るノーツ |
| Long | 同じノーツを複数回切るノーツ |

Direction は、上下左右と斜めを含む8方向から選びます。Long の長さは現行ゲームでは曲線や帯の長さではなく、主に必要カット回数 `count` として扱われます。

### Snap

Snap は、ノーツを拍の区切りへ揃える機能です。たとえば 1/4、1/8、1/16、1/32 のように、細かい値ほど短い間隔へ配置できます。

- 大まかな配置は粗い Snap、細かなリズムは細かい Snap が便利です。
- Snap を変更しても、すでに置いたノーツが自動で移動するとは限りません。
- 表示中の Snap 値が、その時点の配置とシークの単位です。
- Easyを「新規」で作ると、最初は **4分（表拍）** になります。Easyは表拍を中心にし、裏拍の積極的な使用は高難易度向けにします。必要ならSnapを手動で変更できます。既存譜面を読み込んでもノーツの時刻を自動で丸めません。

### アプリ内のプレイ画面

中央上部に3Dのプレイ画面を表示します。右側の **「▶ 再生」** または `Space` で、音源・タイムラインと一緒にノーツが奥から手前へ流れます。UnityのPlayモードへ切り替える必要はありません。

- 未保存の配置・色・方向・ロングの変更もそのまま反映します。
- 一時停止でその場の映像が止まり、スライダーや矢印キーでシークすると移動先の状態を表示します。停止ボタンは先頭へ戻ります。
- **「拡大」** で中央をプレイ画面に、**「編集に戻る」** でタイムライン付きの表示に戻せます。上部の **「プレイ画面」** をオフにするとタイムラインを広く使えます。再生すると再び表示します。
- 本編のノーツ外観・方向矢印・同時線・ロング残数と接近速度を使い、判定時刻で自動的に消える確認用の映像です。背景は固定の通路で、セーバー操作・採点・切断効果音はありません。
- 「ゲームと同じ表示補正」はタイムラインと映像の両方に一度だけ適用します。シーンや譜面ファイルの保存、プレイ記録の更新は行いません。

### 曲に合わせて打ち込む（PC録音）

1. 音源を選び、BPM・グリッド原点・OFFSETを合わせ、録音を始めたい位置へシークします。
2. 画面上部の **「録音」** に切り替えます。右側の「録音で作る」からも開けます。「編集」で通常のタイムライン中心の画面に戻ります。曲を止めて作る場合は「ステップ」を使います。
3. **「録音開始」または `R`** を押します。既定では音付きの4拍カウント後、現在位置から曲が流れます。
4. 曲に合わせて **`D` / `F`（青）、`J` / `K`（赤）、`G`（金）** を押します。**`H`ならF＋J、`B`ならD＋Kを1キーで同時打ち**できます。中央の同時打ちボタンも同じ操作です。各キーは中央のXYマーカーの場所へ入力します。中央のXYパッドへ **左クリックで青、右クリックで赤、Shift＋左クリックで金** を、その場所に直接打ち込めます。
5. **`Space` / `Esc` / 録音終了** で停止します。そのまま再生して確認し、通常のタイムラインやXYパッドで調整して保存します。

- 短押しはTAP、250ms以上の長押しはLONGです。長さはキーを離すまでの曲の時間で決まり、カット回数は右の設定を使います。「長押しをLONGにする」をオフにすると押した瞬間だけを記録します。
- **打ち間違いは録音を止めずに修正**できます。`Backspace`または中央の「⌫ 1打戻す」で直前の入力だけを取り消します。H/Bや同時打ちボタンからの入力は青赤まとめて戻し、既存譜面を消しません。キーを長押ししても取り消すのは1打だけです。もう1打戻すときは一度離して押し直します。
- 録音終了後は、中央の **「聴き直す」または`Enter`** で今回の録音開始位置から再生できます。新しいノーツは追加せず、録音した配置を3D画面で確認できます。
- **「今回を録り直す」または`Shift＋R`** は、今回の録音分を取り消し、同じ開始位置から録音を始め直します。4拍カウントの設定も引き継ぎます。録音中・録音終了後のどちらでも使え、元からあったノーツは残します。取り消した録音もUndoで復元でき、カウント中に中止した場合も戻せます。録音後にノーツや曲設定を編集した場合は、その編集を消さないよう録り直しを止めます。必要なら編集をUndoするか、Rで追記録音してください。
- **同時打ちは1キー・1クリックで青赤2個を追加**します。`H`／「H 同時打ち F＋J」はFとJ、`B`／「B 同時打ち D＋K」はDとKの配置を使います。左右の横位置・高さはそれぞれ自由に設定でき、「反対色へ左右反転」で対称配置も作れます。左右の始点はSnapオフでも同じ時刻になり、長押しすると両方を同じ長さのLONGにします。単打との併用も可能です。カウント中から押し続けたキーは、一度離してから入力してください。
- **横位置・高さは各キーごとに独立**しています。右の「打ち込み位置」でキーを選び、X（−2.5〜2.5）・Y（−1.5〜1.5）を数値指定できます。数値は位置グリッドへ丸めず、入力した精度で保持します。座標倍率は通常の譜面設定と共通です。
- **録音中も位置を変更できます。** `1〜5`でD/F/G/J/Kの調整対象を選び、`Alt＋矢印`で移動、`Alt＋Shift＋矢印`で0.01刻みに微調整します（矢印だけはどのモードでもシークです。録音中の矢印は何もしません）。位置グリッドは自由／4／8／16／32分割で、自由配置の `Alt＋矢印` は0.05刻みです。グリッドは次のクリック位置と `Alt＋矢印` に適用し、既存ノーツは移動しません。
- XYパッドは上が+Y、右が+Xです。**マーカーを左ドラッグすると録音中も位置だけを調整**できます。つかんだ瞬間に座標が飛ばず、ノーツも追加しません。中央の「クリック入力／位置調整」で操作を切り替えられ、Alt＋ドラッグでも一時的に位置調整できます。停止中は配置の準備になります。録音中の「クリック入力」では空白へ左クリックで青、右クリックで赤、Shift＋左クリックで金を打ち込みます。選択キーが青なら左クリックにその青キー、赤なら右クリックにその赤キーを使い、それ以外はF/Jを使います。金はGです。「位置調整」中もD/F/G/J/KやH/Bのキー入力は使えます。
- **「左右連動」** をオンにすると、選択キーと反対色のキー（D↔K、F↔J）のXを対称・Yを同じにして動かせます。ドラッグ・数値・矢印のどれでも連動し、金の位置は独立しています。右の高さ「低／中／高」で高さを素早く切り替え、数値やShift＋矢印で微調整できます。左右連動は個人設定として保存します。
- **配置メモリーA・B・C**には5キーのXY、位置グリッド、左右連動を登録できます。各配置の横の「保存」または`Shift＋F1/F2/F3`で登録し、A/B/Cボタンまたは`F1/F2/F3`で呼び出します。録音中も切り替えられ、次の入力から反映します。既存ノーツや保持中のLONGは動きません。登録した配置はエディターを閉じても個人設定に残ります。
- 長押し中に次の入力位置を変えても、すでに打ったロングは押した瞬間の座標を維持します。「反対色へ左右反転」でD↔K、F↔JのXを反転・Yを維持した配置を作れます。「初期配置」で5キーの配置を戻せます。キー配置と位置グリッドはエディターを閉じても個人設定に保存します。
- 中央には現在時刻付近のノーツ位置も枠で表示します。下部の「譜面を見る／3Dを見る」で配置とプレイ映像を切り替えられます。方向ノーツは録音前に左の「方向」と矢印を選びます。
- 「入力を左のSnapへそろえる」は既定でオンです。始点・ロング終端を、拍子変更を含む現在のグリッドへそろえます。オフでは押した時刻をそのまま使います。
- 「入力補正 (ms)」は正の値で入力時刻を早めます。音声サンプル位置を基準に、曲のOFFSETと入力補正を一度だけ差し引きます。「ゲームと同じ表示補正」は録音データへ反映しません。
- LONGのカット回数と入力補正は「詳細設定」、キー一覧は「操作ガイド / ショートカット」を開いて確認できます。よく使う位置調整や録音操作を先に表示します。
- 録音は既存譜面への**追記**です。同じ時刻・位置・色の重複とキーの長押しリピートは追加しません。**1回のUndoで録音1回分を取り消し、Redoで戻せます。** 無入力やカウント中の中断では譜面も履歴も変わりません。
- 位置は録音中も調整できます。BPM・音源・時間Snap・種類などの変更と既存ノーツの編集は停止後に行います。停止中のシークは矢印・スライダー・ホイールが使えます。ウィンドウからフォーカスが外れたとき、音源が終わったとき、保存・Undo・シーク時には録音を終了し、押し続けているロングもそこまでで確定します。
- 録音中にテンキーの `1〜9` を押すと、次に打つノーツの方向が変わります（1テイクの途中で方向を変えられます）。
- 録音だけではファイル保存されません。仕上げ後に通常の「保存」または `Ctrl+S` / `Cmd+S` を使ってください。

### 曲を止めて1ステップずつ作る

上部の **「ステップ」** を選ぶと、再生停止中にD/F/G/J/KやH/B、中央の単打・同時打ちボタン、XYパッドで現在の拍へ配置できます。音源をまだ選んでいなくても使えます。

- 入力時刻は左側のSnapへ合わせます。音声時計・入力補正は使わず、タイムラインに置く場合と同じ譜面時刻です。
- 既定では**入力キーやマウスボタンを全部離してから次のSnapへ進みます**。FとJを一緒に押した場合も同じ拍に入り、H/Bは1回のUndoで両方を戻せます。押し続けによる連打や同時刻・同じ位置・同じ色の二重登録はしません。
- 「キーを離すと次のSnapへ進む」をオフにすると、同じ拍に留まって配置できます。**Tab＝次へ／休符、Shift＋Tab＝前へ**でも移動できます。7/8拍子などの小節頭や、途中の拍子変更点を飛び越しません。
- 種類・方向・LONG回数は左のパレットを使います。ステップ入力では長押し時間をLONGの長さにはしません。LONGの長さは通常の選択ノーツ詳細で調整できます。
- **Space／「確認」**で再生できます。再生中はステップ入力を止め、キーによる意図しない追記を防ぎます。Ctrl+Z／Ctrl+Yで配置を取り消し・復元できます。
- 位置のドラッグ・左右連動・配置メモリーは録音と共通です。「位置調整」はクリックで配置を変えるだけにする設定で、キーからの入力は引き続き使えます。
- **同じ拍のノーツをまとめて編集**できます。「次へコピー」／Ctrl+Dは同時打ち・方向・LONGの長さを保って次のSnapへ複製し、その拍へ移動します。押し直すと繰り返し配置できます。コピー先に同時刻・同じXY・同じ色のノーツがある場合は、そのノーツを残して重複を避けます。
- 「左右反転」／Ctrl+Mはこの拍のX・赤青・カット方向をまとめて反転。「削除」／Shift+Deleteはこの拍だけを削除します。いずれも1回のUndoで戻せます。再生中・キー保持中・文字入力中は操作しません。
- **PageUp／PageDown**または「前のノーツ／次のノーツ」で配置済みの時刻へ移れます。自動で次へ進んだ後の修正にも便利です。XYパッドではこの拍のノーツを太枠、前後のノーツを薄い枠で表示します。
- **`Backspace` で直前の1打を取り消し、その拍へ戻ります**（録音中の `Backspace` と同じ意味）。矢印はシーク、位置の調整は `Alt＋矢印` です。テンキーで今の拍のノーツに方向を付けられます。

### 音源の設定

音源を選ぶと、タイムライン上の波形、再生、一時停止、シークを使って譜面と曲を合わせられます。

- BPM は曲のテンポに合わせます。
- BPM を変更しても、本編の再生・判定で基準になる `time` は維持されます。`beat` は表示や編集を補助する値として、新しいBPMに合わせて更新されます。
- オフセットは曲と譜面全体のずれを補正します。
- 正のオフセットは、本編上でノーツを後ろへずらす方向です。
- 再生カーソルは実際の音声サンプル位置に追従します。再生ボタンを押してからの経過時間では進めません。
- 「ゲームと同じ表示補正」は既定でONです。同じUnity Editorでプレイするときの判定調整値を再生カーソルにも適用し、現在値を表示します。波形・ノーツの保存時刻・曲のオフセットは変わりません。波形そのものの時刻を確認するときはOFFにできます。
- 個人の機器に合わせた判定調整を、曲ごとのオフセットやノーツ時刻へ重ねて書き込まないでください。ビルドしたゲームとUnity Editorでは設定の保存場所が異なるため、比較時には双方の判定調整値も確認します。
- 音源が鳴らない場合は、AudioClip の選択とインポート完了を確認してください。
- エディターで選んだプレビュー用AudioClipと、保存先フォルダーにある本編用 `audio.mp3` / `audio.ogg` / `audio.wav` が異なる場合は警告が表示されます。警告を確認し、意図した音源か確かめてから保存してください。

## Undo / Redo

配置、削除、移動、種類や色の変更は、Undo / Redo の対象です。大きな範囲を編集する前には、通常の保存も行ってください。

数値入力後にタイムラインやXYパッドをクリックすると、キー操作の対象が譜面へ戻ります。ドラッグ中にUndoした場合も、そのドラッグは終了するため、マウスを動かしても戻したノーツを再移動しません。

## ショートカット

キーは**モードによらず同じ意味**にそろえています。画面下の帯に、いまのモードで効くキーを表示します。

| 操作 | ショートカット |
|---|---|
| 再生 / 一時停止 | `Space` |
| Snap 単位でシーク（どのモードでも） | `←` / `→`・`↓` / `↑`（録音中は無効） |
| 前後の小節頭へシーク（拍子変更対応） | `Shift+←` / `Shift+→` |
| 連続シーク | マウスホイール（1ノッチ＝1拍、`Shift` で Snap 1つ分） |
| タイムラインをズーム | `Ctrl+ホイール` / `Cmd+ホイール` |
| 位置を動かす（編集: 選んだノーツ / 録音・ステップ: 選んだキー） | `Alt+矢印`（`Alt+Shift+矢印` で0.01刻み） |
| 方向を付ける | `Q W E / A S D / Z X C`・テンキー `1〜9`（録音・ステップではテンキーだけ） |
| 前 / 次のノーツへ | `PageUp` / `PageDown` |
| 選択（範囲）を複製。選択がなければ今の拍を次の Snap へコピー | `Ctrl+D` / `Cmd+D` |
| 選択（範囲）を左右反転。選択がなければ今の拍 | `Ctrl+M` |
| 赤と青だけを入れ替え | `Ctrl+Shift+M` |
| 今の拍のノーツを削除 | `Shift+Delete` |
| 選んだノーツ・範囲を削除 | `Delete`（編集では `Backspace` も） |
| 範囲の始め / 終わり / 解除 | `[` / `]` / `Esc` |
| 範囲をコピー / 今の位置へ貼り付け | `Ctrl+C` / `Ctrl+V` |
| 選択（範囲）の時間を ±1 Snap | `Ctrl+↑` / `Ctrl+↓` |
| 打ち込みパッドの録音開始 / 終了 | `R` / `Space`・`Esc` |
| 録音中の単打（青 / 金 / 赤） | `D`・`F` / `G` / `J`・`K` |
| 録音中の同時打ち（F＋J / D＋K） | `H` / `B`（長押しで左右ともLONG） |
| 直前の1打を取り消す（録音・ステップ） | `Backspace`（同時打ちは左右まとめて。ステップではその拍へ戻る） |
| 録音中に次に打つノーツの方向 | テンキー `1〜9` |
| 録音終了後、録音開始位置から聴き直す | `Enter` |
| 今回の録音を取り消し、同じ位置から録り直す | `Shift+R` |
| 調整するキー（D/F/G/J/K）を選ぶ | `1〜5`（録音・ステップ） |
| 配置A/B/Cを呼び出す / 保存する | `F1`・`F2`・`F3` / `Shift`付き |
| ステップ入力で次へ（休符） / 前へ | `Tab` / `Shift+Tab` |
| 編集ツール（選択 / 配置 / 消去） | `1` / `2` / `3`（編集） |
| 保存 | `Ctrl+S` / `Cmd+S` |
| Undo | `Ctrl+Z` / `Cmd+Z` |
| Redo | `Ctrl+Y` / `Cmd+Y`（環境により `Ctrl+Shift+Z` / `Cmd+Shift+Z`） |
| タイムライン上のノーツを削除 | 右クリック（再生中は無効） |

`Ctrl+D`・`Ctrl+M`・`Shift+Delete`・`PageUp/Down` と方向キーは、押し続けても1回だけ働きます（離して押し直すと次の操作）。入力欄へ文字を入力している間は、誤操作防止のため一部ショートカットが無効になります。

## 保存先と本編のファイル仕様

本編が読む曲データは、次のフォルダーへ保存します。

```text
Assets/StreamingAssets/Songs/<曲フォルダー名>/
├─ chart.json
├─ chart_easy.json
├─ chart_normal.json
├─ chart_hard.json
├─ audio.mp3、audio.ogg、または audio.wav
└─ cover.png（任意）
```

- 曲フォルダーに `chart.json` か `chart_<難易度>.json` があれば曲一覧に出ます。
- 難易度別ファイルがある場合、本編は選択難易度の `chart_<難易度>.json` を優先します。
- 難易度別ファイルがない場合、本編は `chart.json` へフォールバックします。
- 保存先はヘッダーの「編集中」の曲・難易度です（「開く・作る」の選択ではありません）。
- 新しく作った譜面や複製した譜面で既存の譜面を置き換えるときは、上書き確認が表示されます。曲と難易度を確認してから確定してください。
- 難易度名は通常 `easy`、`normal`、`hard` を使用します。
- 音源は `audio.mp3`、`audio.ogg`、`audio.wav` のいずれかの名前にします。
- ジャケットを付ける場合は `cover.png` にします。
- 曲フォルダー名は本編内の曲IDとして使われるため、保存後に不用意に変更しないでください。

Normal を保存すると、`chart_normal.json` と `chart.json` が同じ内容に更新されます。Easy / Hard の保存では `chart.json` に触れません（Hard を先に保存しても、Hard の内容が Easy・Normal の代わりに出ないようにするため）。Normal がまだない曲で Easy / Hard を保存すると、「Normal がまだ無いため、本編の Easy / Normal は選べません」と表示します。保存後は目的の曲フォルダーに譜面と音源が揃っていることを確認してください。

ファイルの使用中などで途中の保存に失敗した場合は、更新済みの譜面を元に戻し、その保存で新しく作った譜面も取り消します。編集内容はウィンドウに残るので、原因を解消して再度保存できます。復元先も使用中になるなど復元まで失敗した場合は、エラーに表示された復旧用データの場所を確認してください。

既存ファイルを保存する前には、バックアップが `Library/3DSaberChartBackups/` に作成されます。このフォルダーはUnityプロジェクト内のローカル作業用領域なので、必要なバックアップは別の安全な場所にも保管してください。

## 旧 Note-Recorder との違い

- 旧版: `Assets/Note-Recorder/Scenes/SampleScene.unity` を開き、Play モードで使用します。
- 新版: Unity メニューから EditorWindow を開き、編集モードのまま使用します。
- 旧版の8×8現在位置表示ではなく、新版は縦タイムラインとXYパッドを組み合わせます。
- 新版は本編の赤・青・金、Tap・Direction・Longを直接意識した作りです。

旧 Note-Recorder のシーンや保存データを削除する必要はありません。両方が同じ本編形式の `chart.json` を扱う場合でも、編集中のファイルを同時に開いて上書きしないでください。

## 現時点のゲーム仕様上の制限

プロセカのような **曲線スライド、曲がるロングノーツ、ノーツ同士を線で結ぶスライド軌道** は、現時点の3D Saber本編の譜面仕様にはありません。

現在の本編が扱うのは、固定座標に出現する Tap、方向指定の Direction、複数回カットする Long です。見た目だけ曲線を追加しても本編は軌道を解釈できないため、曲線スライド対応にはエディターだけでなく、譜面JSON、ノーツ生成、表示、判定処理の拡張が必要です。

## 困ったとき

- 曲一覧に出ない: 曲フォルダー内に `chart.json` か `chart_<難易度>.json` があるか確認します。
- Unity が落ちて編集が消えた: 同じ曲・難易度を開くと、右上に下書きの案内が出ます（5分ごとの保存なので、直前の数分は戻らないことがあります）。
- 難易度が切り替わらない: `chart_easy.json` などの名前と保存先を確認します。
- 音源が鳴らない: `audio.mp3` / `audio.ogg` / `audio.wav` の名前と、選択中のAudioClipを確認します。
- ノーツが曲とずれる: BPMとオフセットを確認し、波形を見ながら先頭の拍を合わせます。
- 新しいメニューが出ない: Unity Console のコンパイルエラーを解消し、再コンパイルを待ちます。
