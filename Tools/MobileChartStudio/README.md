# Saber Tap Studio

スマホで開く：[Saber Tap Studio](https://saber-tap-studio.metuji48.chatgpt.site)（ログイン不要）。URLを知っていれば利用できます。音源と下書きは各端末内に保存されます。

スマホの音源を聴きながら、タップと長押しで3D-Saberの譜面を作るエディターです。インストール不要でブラウザから使え、音源と下書きは端末のIndexedDBに保存します。サーバーへの音源・譜面の送信、解析API、外部CDNは使いません。

## 使い方

1. 「音源を開く」でスマホ内のMP3 / M4A / WAVなどを選びます。デコード可否はブラウザの対応形式によります。
2. 「録音開始」を押します。4拍のカウントの後、音楽に合わせてパッドをタップします。左側は青、右側は赤。押した位置も記録します。色を固定することもできます。
3. 0.24秒以上の長押しはロングです。2本指で左右を同時に記録できます。指が離れた時点で記録が確定し、端末内に自動保存します。
4. 「確認」でノーツが奥から手前へ流れます。シーク、0.75倍 / 0.5倍、Undo / Redo、ノーツごとの時刻・座標・色・方向・回数・長さの修正ができます。
5. 「譜面を書き出す」で `chart_easy.json` / `chart_normal.json` / `chart_hard.json` を保存します。

通常の録音は既存のノーツに追記します。一時停止後の「戻す」で1回の録音をまとめて取り消せます。「直前の録音をやり直す」は直前の録音前の譜面に戻して、同じ開始位置から録音を始めます。個別の入力は一覧で選び「削除」します。「集中」はスマホの入力面を広げます。保存した曲は「曲・保存」から再開できます。別の譜面JSONを開いたときは、前の下書きを残して新しい下書きを作ります。

## 区間の録り直しと調整

- 「区間を決めて録音・確認」でA（開始秒）とB（終了秒）を指定します。「今の位置を A / B に」も使えます。「この区間だけ再生」をONにすると、Aから始まりBで自動停止します。音声の停止時刻は描画とは別に予約します。
- 「区間内を録り直す」をONにすると、入力した録音で再生した区間を置き換えます。Aより前とB以降のノーツは残ります。途中停止では停止した時刻以降も残り、入力なし・カウント中の中断では既存ノーツを消しません。Aより前に始まるロングもそのまま残します。区間は曲を開くたびOFFへ戻します。
- 「タップでBPMを測る」を拍に合わせて4回以上押し、「BPMに適用」を押します。録音済みノーツの時刻は変わりません。「メトロノーム」は再生速度と拍の始まり・オフセットに合わせて鳴ります。
- ノーツを選ぶと編集画面が開きます。枠内のタップで位置、10msのボタンで時刻をすぐ変更します。「拍にそろえる」は録音設定の刻みを使い、設定が「なし」の場合は16分音符へそろえます。数値・色・方向の欄は「変更を適用」で保存します。前後のノーツへも移動できます。
- 再生速度・入力色・入力補正・カウント・タップ音・メトロノームなどの設定を下書きと一緒に端末へ保存します。

## タイムライン・まとめて編集

- 録音画面の「譜面」で、青・赤・金のノーツとロングの長さを時刻順に表示します。曲全体／20秒／10秒／5秒／2秒に切り替え、前後の区間へ移動できます。四角または下の一覧から個別編集、空いた場所のタップでシーク、「ここから聴く」で試聴できます。
- タイムラインの「今の位置を A / B に」で編集範囲を指定し、「A–Bを編集」を開きます。録音画面のA/B数値からも指定できます。区間再生がOFFでも、まとめて編集にはA/Bを使います。
- 対象の色を選び、時刻をms単位で移動、指定秒から区間コピー、配置・矢印の左右反転ができます。反転時は青と赤の交換を選べます。開始A以上・終了B未満に始まるノーツが対象です。ロングの末尾を含めて音源外へは移動・コピーできません。
- コピー元を残し、各操作は1回の「戻す」で取り消せます。コピー先に元からあるノーツは残るため、対象数と結果の重なりを確認してください。
- 「曲・保存」→「別の難易度・コピーを作る」で、同じ音源とBPM・オフセットを使う別の下書きを作れます。ノーツのコピー／空の譜面を選べます。元の下書きは残ります。

## 音源入りバックアップ

「ゲームで使う」→「音源ごとバックアップ」→「バックアップを保存」で、現在の音源・譜面・設定を1つの `.saber` ファイルに保存します。元の音源をそのまま格納し、サーバーへ送信しません。端末移動やブラウザのデータ削除前に利用してください。

同じサイトの「バックアップを開く」で復元すると、新しい下書きとして音源と譜面を一緒に端末へ保存します。元の下書きは上書きしません。音源の形式は復元先ブラウザでも再生できる必要があります。`.saber` はこのエディター用です。本編へ渡すときは譜面JSONと音源を書き出してください。

## 本編へ取り込む

1. 譜面JSONと、それに使った同じ音源をPCへ渡します。M4Aなど本編が直接読めない音源は「音源をWAV保存」で `audio.wav` にできます。
2. Unityの `3D Saber/譜面エディター` でJSONを読み込み、曲フォルダー・難易度を選んで保存します。音源も選んで同期を確認します。
3. `Assets/StreamingAssets/Songs/<曲ID>/` に `audio.mp3` / `audio.ogg` / `audio.wav` と譜面をそろえます。音源は複数形式を同時に置かず、採用する1つにそろえてください。
4. 新しい曲には `chart.json` も必要です。Unityエディターの保存はNORMALを基本譜面にも保存し、EASY/HARDでも基本譜面がなければ作成します。既存曲を置き換えるときは保存確認とバックアップを確認してください。

Web版からゲーム本体のファイルを直接上書きしません。現行本編のロングは「押し続けて判定するノーツ」ではなく「同じ場所を複数回切るノーツ」です。長押しの継続時間を `lengthMs`、回数を `count` に変換しています。自動の回数は長さとBPMから決め、後から手動で直せます。

## オフラインと保存

HTTPSで最初に開き、「オフラインで使用できます」と出たらアプリ本体の保存が完了しています。iPhoneでは共有メニューから「ホーム画面に追加」、Androidではブラウザからインストールできます。保存済みの音源と下書きは、同じブラウザ／ホーム画面アプリから開いてください。ホーム画面に追加した後に音源を読み込む使い方を推奨します。

保存は端末ごとです。他のスマホやPCへ自動同期しません。ブラウザデータの削除やOSによるストレージ解放で失われる可能性があるため、音源入りバックアップや完成した譜面のJSONも保存してください。保存に失敗した場合は未保存と表示し、編集中のデータを残します。音源は100MB・20分までですが、メモリが少ない端末では短い圧縮音源を使ってください。

## タイミング

- 音声出力の時計を入力イベントの時刻へ対応させます。描画フレーム数では時刻を決めません。
- `offsetMs` は保存時に一度だけ取り除き、本編が一度だけ足す形式です。
- スロー再生でも元の音源の秒数で保存します。音程も下がります。
- 拍への整列は初期OFFで、新しい入力だけに適用します。既存ノーツの実時刻、拍子、座標スケール、未知のメタデータを保持します。
- 可変テンポの既存譜面は読み込み時に注意を表示します。固定BPMの整列をそのまま使わず、必要な場所を音源時刻で編集してください。
- 「入力補正」はスマホで打つタイミング用です。ゲーム側の個人判定設定を重ねて書き込まないでください。Bluetooth音声の遅延は実機で確認が必要です。
- アプリを離れると一時停止します。OSによる突然の終了直前の入力は保存が間に合わない場合があります。

## 開発と確認

ビルド不要のES Modulesです。`dist` をHTTPで配信してください。例：`python -m http.server 4193 --directory dist`。ファイルを直接開く `file://` は未対応です。公開時の配信内容は `dist` のみです。

`npm test` で時刻変換、長押し、同時入力、録音単位のUndo/Redo、区間録音の境界・途中停止、BPM測定、音声時計とメトロノーム、オフラインキャッシュ、WAV出力、区間コピー・反転・移動、別難易度、バックアップ形式と破損検出、タイムラインの範囲・選択を確認できます。`SABER_SONGS_DIR` を本編のSongsディレクトリへ設定すると、実譜面の読み書き互換も検証します。Service Workerのアセットを変更したら `sw.js` のキャッシュ名も更新してください。更新を検出した場合は「更新を反映」を表示し、保存してから再読み込みします。録音中の画面は強制再読み込みしません。初期版からの更新では一度再読み込みが必要です。

2026-10-07の確認：32件の自動テストと27の既存難易度譜面のゲーム用フィールドの往復比較。PCブラウザを390px幅にし、検証用音源と譜面の読込、区間の途中停止・自動停止、録音単位のUndo/Redo、直前の録音のやり直し、位置変更、10ms調整、拍への整列、BPM測定、下書きと設定の再読み込みを操作しました。実際にダウンロードしたJSONの編集結果と読み書き互換も確認しました。追加の操作確認では、タイムラインからの編集・試聴、区間コピー（8→12ノーツ）とUndo/Redo、50ms移動、左右反転、難易度複製と空の下書き、音源入りバックアップの保存・復元を確認しました。iPhone / Androidの実機、2本指の実タッチ、Bluetooth、インストール後の完全オフラインでの通し作業は未確認です。
