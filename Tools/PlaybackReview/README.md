# プレイレビュー・AI修正

Unity の **3D Saber → プレイレビュー・AI修正** から開きます。Play ボタンを押す必要はありません。
既存譜面から自動プレイを描く専用画面です。Easy / Normal / Hard / E の実ファイルを選べます。

1. 曲・難易度を選び「開く / 再読込」。シークバー、秒数入力、±1秒、±1コマ（1/60秒）で位置を探します。「再生」は曲フォルダーの音源と同期します。
2. 「今をAに」「今をBに」または「現在±1秒」で対象区間を決めます。A–Bループも使えます。区間のノーツ一覧を選ぶと、そのノーツの少し手前で停止します。選択は複数可能です。
3. 「ここを指摘」で停止して現在±1秒を指定できます。映像をクリックすると黄色い十字で位置を示せます。「赤ノーツを少し右へ」「この同時を50ms遅く」「このフリックを通常に」などを書き、「指摘を追加」。別の時刻にも指摘を追加できます。
4. 「AIへの依頼を書き出す」で、プロジェクト直下 `PlaybackReviews/<日時-ID>/` に依頼を保存し、依頼文をコピーします。このチャットへ貼り付ければ、このPCのファイルを読めるAIが作業できます。別のAIへ渡す場合は依頼フォルダーのファイルを添付します。
5. AIに `reply.json` を作ってもらい「AIの返信JSONを開く」。**変更前 / 変更案** を切り替え、同じ位置を再生して確認します。「この修正を適用」の後も、まだ本編ファイルは変更されません。
6. 「本編へ保存」で反映します。「適用を1回戻す」で戻せます。保存前のファイルは既存の `Library/3DSaberChartBackups/` に残ります。別窓の譜面エディターで同じ曲を開いている場合は、保存済みの内容を再読込してください。

窓を閉じた後も「依頼を再開」で `request.json` を選ぶと続きを扱えます。依頼後に本編の譜面が変更されている場合は上書きせず、新しい譜面で依頼し直します。レビュー依頼と撮影画像はGitに含めません。

## 場所を探す・指摘を整理する

- 「譜面 / 指摘」には青・赤・金のノーツとロングの長さ、停止位置、A–B区間、指摘の番号を表示します。曲全体 / 10秒 / 5秒 / 2秒に切り替え、拡大時は下のバーで表示区間を移動します。「現在位置」で再生位置に戻せます。変更案の表示中はタイムラインと一覧も変更案へ切り替わります。
- タイムラインをクリック・ドラッグしてシークします。ドラッグ中は音声を止め、再生中に始めた場合は離した位置から再開します。Shift+ドラッグでは左右どちらの方向からでもA–B区間を指定し、その位置で停止します。
- 「前のノーツ / 次のノーツ」は同時押しを一つの時刻として移動します。「区間を全選択」「選択解除」で対象をまとめて指定できます。
- 指摘は時刻順に表示します。タイムラインの番号や「この箇所へ」で画像の時刻・区間・画面位置・選択ノーツを呼び戻せます。「編集」→「指摘を更新」で同じ指摘を書き直し、「直前に削除した指摘を戻す」で1件戻せます。
- 「タイミング / 配置 / 難しさ」で文章のひな型を入力できます。入力中の文章がある場合は書き出しを止め、追加・更新漏れを防ぎます。書き出し後に指摘を変更した場合、依頼文の再コピーと返信の読込には書き出し直しが必要です。
- 報告文には曲・難易度・指摘数・時刻順の指摘と対応する画像名を含めます。個別ノーツを選択していない指摘も明記します。

## ノーツが来てほしい時刻を打ってAIに配置を頼む

1. 再生開始位置へシークし、映像下の **「▶ タイミング記録」** を押します。停止中なら再生を始め、再生中ならそのまま記録モードに入ります。
2. ノーツが来てほしい瞬間に **映像を左クリック / 「ここにノーツがほしい」ボタン / Tキー** を押します。再生を止めずに連続記録できます。クリックした座標は配置指定にせず、時刻だけを記録します。色・位置・種類はAIへの依頼で決めます。
3. **Backspace / 「1打戻す」** で直前の入力を取り消せます。Spaceは再生・一時停止、Escまたは「記録を終了・指摘に追加」で今回のタイミングを1件の指摘にまとめます。
4. 必要ならその指摘を編集し、「青赤交互」「サビなので多め」などを追記してから、通常どおり **「AIへの依頼を書き出す」→依頼文をこのチャットに貼り付ける**。返信JSONで配置案を確認・適用します。

- 押した瞬間の音声時計を使います。キーを押しっぱなしにしても連打にならず、文章入力中はT/Backspaceを記録操作に使いません。停止中は現在のシーク位置を記録できます。
- 「拍に合わせる」がONならその刻みに寄せます。同じ時刻への重複入力は1打にまとめます。記録した時刻はタイムラインの緑の目印で確認できます。
- 途中の記録も下書きに保存します。開き直した際は停止状態で復元され、「タイミング記録」で続けるか「指摘に追加」で確定できます。未確定の記録がある間は書き出しと返信読込を止め、依頼への入れ忘れを防ぎます。
- 各希望時刻は `requestedNoteSeconds` に音源先頭からの秒で保存し、依頼文にも全件を列挙します。AIは `note.time = requestedNoteSeconds × 1000 − chart.offsetMs` で到達時刻へ変換します。画像は指摘ごとに1枚なので、連打しても打数分の画像を生成しません。

## 波形・拍で合わせる、ノーツを直接選ぶ

- 「波形」をONにすると、音源の波形をノーツの後ろに表示します。拡大表示には拍の線も出ます。波形を読み出せない音源では案内を表示し、シークとノーツ表示は引き続き使えます。
- 「拍に合わせる」はOFF / 1拍 / 1/2拍 / 1/4拍。タイムラインのクリック・ドラッグとShift区間指定を、BPM・拍の原点・OFFSET・テンポ地図に合わせます。譜面自体は変更しません。秒数入力や1コマ送りでは自由に微調整できます。
- タイムラインのノーツを直接クリックすると、そのノーツを選び、到達の0.2秒手前で停止します。Ctrl / Cmd+クリックで追加選択・解除できます。区間には選択ノーツとロング末尾を含めます。白い枠が選択の目印です。空いた場所は従来どおりシーク、Shift+ドラッグはノーツの上でも区間指定を優先します。
- タイムライン上でホイールを動かすと、カーソルが指している時刻を中心に拡大・縮小します。上部の倍率ボタンでは現在の再生位置を中心に切り替えます。

## 指摘区間を聴き直す・修正案を比較する

「区間を聴き直す」はAの0 / 0.5 / 1 / 2秒手前から再生し、Bの0.35秒後で止まります。曲の先頭・末尾では音源の範囲に収めます。A–BループがONなら、手前の時間も含めて繰り返します。報告するA/Bの値は変わりません。通常の再生やシークへ切り替えると区間試聴を終了します。

返信を読み込むと、追加・変更・削除の件数と、6件ずつの変更一覧が出ます。件数が多くても全ページを確認できます。到達時刻・座標・種類・矢印・回数・ロングの長さを変更前後で表示します。

- 「この変更へ移動」「前の変更 / 次の変更」で対象へ移動します。時刻が移動した修正では、移動前と移動後の両方を含む区間を指定します。
- 選択中の「この変更を聴き直す」で、その区間を手前から再生できます。
- Bキーで同じ再生位置の「変更前 / 変更案」を切り替えます。文章入力中は切り替わりません。
- 波形・拍補正・拡大率・試聴の手前時間・確認中の変更とページも下書きに保存します。以前の下書きも開けますが、旧形式の変更案は以前の要約表示を引き継ぎます。

| キー | 操作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 1秒戻る / 進む |
| Shift+← / → | 1コマ戻る / 進む |
| [ / ] | 現在位置をA / Bにする |
| N | 現在±1秒を指摘し、文章欄へ移動 |
| B | 変更前 / 変更案を切り替える |
| T | タイミング記録モードで、ノーツ到達の希望時刻を記録 |
| Backspace / Esc | タイミング記録モードで、1打戻す / 記録を指摘に追加して終了 |
| Ctrl+Enter / Cmd+Enter | 入力した指摘を追加 / 更新 |

文章や数値の入力中は、追加・更新以外のショートカットは動きません。

## 下書きの自動保存

指摘・入力中の文章・再生位置・区間・選択ノーツ・確認中の変更案を2秒ごとと窓を閉じるときに保存します。同じ曲・難易度を開くと復元します。未保存の譜面修正と、その適用を戻す履歴も復元対象です。本編への書き込みは引き続き「本編へ保存」で行います。

保存先はこのPCの `Library/3DSaberPlaybackReview/` です。元譜面のハッシュごとに下書きを分けるため、外部で譜面が変わった場合は古い指摘を混ぜず、新しい下書きで始めます。古い下書きファイルは残ります。Libraryを削除すると下書きも失われるので、持ち出すレビューは「AIへの依頼を書き出す」で保存してください。自動保存に失敗した場合はパネル下部に理由を表示します。

## AIに渡す内容

- `request.json`: 曲・難易度、変更前の譜面、譜面ハッシュ、各指示の秒数、対象ノーツの元配列インデックス、画面位置、ノーツ到達の希望時刻。
- `chart-before.json`: 本編形式の変更前譜面。
- `frame-<指示ID>.png`: その指示の停止位置を1280×720で描画した画像。画面上の指摘位置も含みます。
- `prompt.txt`: コピーされる依頼文。
- `patch-template.json`: 返信JSONのひな型。

音源は依頼に複製しません。ツールからAIへの自動送信・API呼び出しはなく、好きなAIとのチャットに依頼を渡す方式です。

## 返信形式

`version`, `songId`, `difficulty`, `baseHash` はひな型の値を保持し、`explanation` に変更理由を記述します。
`operations` は `action: replace / delete / add` の配列。replace/delete の `index` は、操作順に変化する番号ではなく、依頼中 `chart.notes` の元の0始まりの番号です。同じ番号への複数操作は拒否します。
replace/add は `note` に全フィールド（beat, time, x, y, type, color, direction, count, lengthMs）を入れます。timeとlengthMsはミリ秒、画面のシークは音源先頭からの秒で、到達時刻は `(time + offsetMs) / 1000` です。
種類は tap/direction/long、色は red/blue/gold/default。Long は count ≥ 2、通常は count = 1 / lengthMs = 0。座標は x ±2.5、y ±1.5 の範囲です。

曲違い・難易度違い・古いハッシュ・不正な数値・音源外への移動・不整合なノーツは適用前に止めます。返信からコードやコマンドは実行しません。譜面の未知メタデータ・テンポ地図・拍子は既存のエディターと同じ変換処理で保持します。

## 表示の範囲

本編のノーツ素材・座標・移動計算と既存の譜面プレビューを利用します。背景は譜面確認用の固定ステージで、スコアHUD・センサー入力・本番のランダム背景や全演出を再現する録画ではありません。今回の対象はノーツの位置・時刻・種類です。

## 返信の差し替えと全件の診断（2026-10-16 追加）

別の返信を読み込むときは、返信全体の検証が通ってから変更案と説明を入れ替えます。「譜面の変更なし」の有効な返信は前の変更案を閉じ、説明だけを保存します。無効な返信では、前の有効な変更案・説明・採否を保ちます。

変更案の差分診断は、同じ時刻に同じ種類の問題が増えた場合も数えます。対象ノーツの内容で比較するので、無関係なノーツの追加・削除で番号がずれただけでは新規問題にしません。

「譜面チェック」と「変更案のチェック」は、エラー・注意の絞り込みと8件ずつのページ送りで全件を確認できます。候補の採否を変更して件数が減った場合も、有効なページに戻ります。未適用の変更案にだけある問題も、この画面で最後までたどれます。
